# Screenplay Studio 2.0 Rubric

每项 0–5 分。

## A. Core Drama

1. 剧本性：是否真正是可见、可听、可演的戏。
2. Premise：核心冲突是否清晰且可持续。
3. Story Engine：是否能持续产生新冲突，而非一次误会。
4. 主角主动性：关键推进是否来自主角选择。
5. 对抗：对手/对抗力量是否会适应和反制。
6. Stakes：代价是否具体并升级。
7. 因果：重大节点是否由此前选择产生。
8. 不可逆性：关键决定是否真正改变可选空间。

## B. Character / Relationship

9. 人物弧：变化是否有行为证据。
10. 核心关系：关系权力、信任或依赖是否持续变化。
11. 角色策略：失败后是否会换策略。
12. 人物声音：主要角色是否可区分。

## C. Structure / Scene

13. 结构：中段、低谷、高潮是否功能明确。
14. Sequence / Episode：中层结构是否有局部目标和结果。
15. 场景：是否有目标、阻力、策略、转折、状态变化。
16. 场景因果：为什么下一场必须发生是否清楚。

## D. Information / Dialogue

17. 信息设计：观众与人物知识状态是否合理。
18. Reveal：揭露是否改变行为和局面。
19. 对白：是否是行动，而非说明书。
20. 潜台词：表面语言与真实目标是否存在有效差异。

## E. Adaptation

仅改编任务评分：

21. Source Integrity：是否准确理解完整源素材。
22. Adaptation Function：是否保留功能而非逐句搬运。
23. Interior Externalization：内心戏是否有效外化。
24. Compression：人物/支线压缩是否不破坏关键因果。
25. Signature Preservation：核心关系、情绪承诺与标志性元素是否仍在。
26. Standalone Screen Story：不读原作是否仍能独立成立。

## F. Continuity / Format

27. Story Bible：事实、时间、伤势、物件、秘密是否稳定。
28. Character Knowledge：角色是否只根据自己应知道的信息行动。
29. 类型承诺：是否兑现目标类型体验。
30. 格式与可读性：是否清楚、简洁、专业可读。

## P0

出现以下任一项时，即使平均分高也不能判 Final：

- 主线因果不成立
- 主角没有实质性选择
- 高潮依赖偶然
- 长篇改编未读结局就锁定方案
- 改编删除导致关键动机/伏笔断裂
- 大量场景无状态变化
- 角色知道不该知道的信息
- 用户要求完整剧本但只给大纲
