# Short Drama Workflow

## 原则

短剧不是切碎的电视剧，也不是更短的电影。

## 单集最小单元

~~~text
具体处境
→ 当前问题
→ 主角行动
→ 反制
→ 状态变化
→ 小兑现或新信息
→ 新后果
~~~

## 观看驱动力

持续检查：
- 观众现在站谁？
- 观众现在最想知道什么？
- 观众现在最期待什么发生？

三者都弱时，不要靠突然反转或切黑补救。

## 有效变化

短剧单位时间内应持续发生至少一种：
- 目标变化
- 关系变化
- 权力变化
- 风险变化
- 信息变化
- 认知变化
- 资源变化
- 秘密状态变化
- 观众预期变化

## 小兑现

优先：

~~~text
兑现旧承诺
→ 改变局势
→ 产生新代价
→ 启动下一轮
~~~

## 禁止

- 固定每 N 秒一个反转
- 每集只靠突然切黑
- 一个误会说开全剧就结束
- 主角反复回到同一受压状态
- 随机新增反派拖集数
- 为快节奏删除人物因果


## 成长不能太顺

短剧的高密度不等于主角可以无阻碍升级。

推荐：

~~~text
获得优势
→ 被看见 / 被怀疑
→ 利益冲突产生
→ 对手试探或反制
→ 主角改变策略
→ 局部兑现
→ 付出真实代价
→ 新问题由结果启动
~~~

对手应由主角的成长自然吸引，而不是随机新增。

可以从熟人索取、道德绑架、偷窃与泄密，逐步升级到小型掠夺者、地方势力、区域组织和战略对手。

主角可以聪明，但不能每次无损获胜。资源损失、时间损失、能力曝光、关系债务、基地损坏都应持续影响后续。

## 重生 / 系统 / 末世短剧

命中此类题材时额外读取：

- `../references/speculative-survival-serial-engine.md`

特别检查：

- 重生是否真的带来可兑现的前期情报优势
- 是否把“知道未来”误写成全知
- 时间线被改变后旧情报是否衰减
- 主角是否在没有必要时公开战略能力
- 物资采购、重量、运输、仓储和消耗是否合理
- 系统能力是否提前定义，禁止临时救场
- 灾难是否从城市功能停摆逐步进入更高阶段
- 动物 / 怪物快速变化是否拥有独立虚构原因

## 长期连载钩子

短剧连载至少维护四层：

~~~text
Episode Hook
→ Arc Hook
→ Season Hook
→ Saga Hook
~~~

本集结尾优先由本集结果自然产生下一压力。

阶段结尾解决一个问题，同时改变故事尺度或规则。

第一季不要同时解释系统来源、全部灾难真相、全部幕后势力和主角特殊性的最终原因。
