# Short Drama Workflow

## 原则

短剧不是切碎的电视剧，也不是更短的电影。

## 单集最小单元

~~~text
具体处境
→ 当前问题
→ 主角行动
→ 反制
→ 状态变化
→ 小兑现或新信息
→ 新后果
~~~

## 观看驱动力

持续检查：
- 观众现在站谁？
- 观众现在最想知道什么？
- 观众现在最期待什么发生？

三者都弱时，不要靠突然反转或切黑补救。

## 有效变化

短剧单位时间内应持续发生至少一种：
- 目标变化
- 关系变化
- 权力变化
- 风险变化
- 信息变化
- 认知变化
- 资源变化
- 秘密状态变化
- 观众预期变化

## 小兑现

优先：

~~~text
兑现旧承诺
→ 改变局势
→ 产生新代价
→ 启动下一轮
~~~

## 禁止

- 固定每 N 秒一个反转
- 每集只靠突然切黑
- 一个误会说开全剧就结束
- 主角反复回到同一受压状态
- 随机新增反派拖集数
- 为快节奏删除人物因果
