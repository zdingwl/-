# Episodic Series Workflow

## 目标

建立能够持续产生故事的剧集系统，而不是把电影剧情拉长。

## 流程

~~~text
Series Premise
→ Series Engine
→ Season Question
→ Season Arc
→ Character / Relationship Network
→ Episode Functions
→ A/B/C Lines
→ Episode Cards
→ Episode Scene Maps
→ Draft
→ Episode Continuity Update
→ Season Review
~~~

## 每集强制

每集必须：
- 有独立职责
- 有本集当前问题
- 有主角主动行动
- 有至少一个状态变化
- 有本集后果
- 给下一集留下真实未完成事项

## 多线

A 线通常推动外部主线。
B 线通常推动核心关系或人物弧。
C 线可承担配角、主题、世界或未来发动机。

多线需要互相产生影响，避免三条线各自独立。

## 季中段

长季中段必须改变发动机状态，例如：
- 调查变逃亡
- 假盟友身份公开
- 权力中心转移
- 问题从“谁做的”变成“主角为何参与过”

不能只重复前几集。

## 每集结束更新

- 人物知道 / 不知道 / 误信什么
- 关系状态
- 时间与地点
- 伤势
- 资源 / 证据 / 物件
- 秘密状态
- Setup / Payoff
