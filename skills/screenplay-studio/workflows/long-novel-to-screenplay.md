# Long Novel To Screenplay Workflow

用于长篇、网文、百万字、多卷、多文件小说直接改成电影、剧集、短剧或动画剧本。

## Phase 1：Source Ingestion

读取：

- references/source-ingestion.md
- templates/Source_Index_Template.md

执行：

~~~text
目录扫描
→ Source Manifest
→ 分块功能索引
→ Canon / Timeline
→ Character Knowledge
→ Relationship Events
→ Setup / Payoff
→ Reveal Ledger
→ 关键段深读
~~~

此阶段不正式写剧本。

## Phase 2：Source Convergence

检查：

- 主线因果
- 结局
- 关键秘密
- 核心关系
- 情绪高点
- 标志性元素
- 后文是否重解释前文

条件不足则继续读，不允许“先猜一个版本”。

## Phase 3：Story DNA

建立：

- protagonist
- external goal
- internal need
- misbelief
- core relationship
- opposing force
- stakes
- dramatic question
- theme question
- central secret
- emotional promise
- ending state

## Phase 4：Adaptation Contract

锁定：

- 目标媒介
- 篇幅/集数
- 忠实度
- 不可改元素
- 可合并元素
- 可新增范围
- 必须保留的标志性场景/关系/结局

## Phase 5：Adaptation Matrix

逐项执行：

- KEEP
- TRANSFORM
- MERGE
- MOVE
- CUT
- INVENT

不要只输出“保留/删除”，必须记录原作功能、新功能和风险。

## Phase 6：影视重构

依次处理：

1. 人物功能与合并
2. 支线压缩
3. 内心戏外化
4. POV
5. Reveal Timing
6. 时间线
7. Screen Causality
8. Story Engine
9. Medium Structure

## Phase 7：Structure

电影：

~~~text
Ending State
→ Sequence Design
→ Beat Sheet
→ Scene Map
~~~

剧集：

~~~text
Series Engine
→ Season Question
→ Season Arc
→ Episode Functions
→ A/B/C Lines
→ Episode Cards
→ Episode Scene Maps
~~~

短剧：

~~~text
Long Engine
→ Arc Blocks
→ Episode Micro-Drama
→ Payoff / Consequence Chain
~~~

## Phase 8：Draft

正式写剧本：

- Scene Heading
- Action
- Character
- Dialogue
- Turn
- Consequence

不要写成小说体。

## Phase 9：State Update

每完成一个单元更新：

- Canon
- Timeline
- Character States
- Relationships
- Character Knowledge
- Objects / Evidence
- Secrets
- Setup / Payoff
- Unresolved Questions

## Phase 10：Adaptation Integrity Review

检查：

- 原作情绪承诺
- 核心关系
- 标志性元素
- 人物动机
- 删除造成的因果断点
- 新增内容是否有必要
- 影视版是否独立成立
- 是否已经变成“另一部作品”

## Phase 11：Script Doctor + Rewrite

按上游到下游：

~~~text
Story Engine
→ Agency
→ Causality
→ Character / Relationship
→ Structure
→ Episode / Sequence
→ Scene
→ Information
→ Dialogue
→ Continuity
→ Format
~~~

完成后统一重写受影响部分。
