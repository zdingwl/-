# Original Screenplay Workflow

## 入口

适用于从概念、人物、主题、类型或零散创意开始。

## 流程

~~~text
Project Brief
→ Premise
→ Logline
→ Audience Promise
→ Story Contract
→ 主角 / 对手 / 核心关系
→ Ending State
→ Story Engine 测试
→ 全局结构
→ Beat / Sequence
→ Scene List
→ Scene Contracts
→ Draft
→ Story Bible
→ Script Doctor
→ Rewrite
~~~

## 强制检查

在大量场景写作前：
- 主角目标是否具体？
- 对手是否能持续反制？
- 失败代价是否实际存在？
- 高潮选择是否已经能想象？
- 结局是否回答核心问题？
- 故事发动机能否自然生成中段？

如果只能靠随机新事件维持剧情，先修发动机。

用户要求“直接完整写”时，可以内部完成上述规划后连续写正文，不需要逐阶段等待确认。
