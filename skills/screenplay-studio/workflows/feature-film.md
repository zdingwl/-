# Feature Film Workflow

## 目标

完成具有单一主要戏剧问题、完整人物弧与高潮闭环的长片剧本。

## 流程

~~~text
Premise / Logline
→ Story Contract
→ Character Arc
→ Ending State
→ Sequence Design
→ Beat Sheet
→ Scene List
→ Draft
→ Script Doctor
→ Rewrite
~~~

## Sequence 思维

每个 Sequence 需要：
- 局部目标
- 阻力
- 新信息
- 转折
- 结果
- 下一段为什么必须发生

不要只盯三幕节点而忽略中间过程。

## 长片检查

- 触发事件是否真正破坏原平衡？
- 主角何时主动承诺进入主线？
- 前半段是否不断收窄选择？
- 中段是否重定义故事？
- 后半段是否由前半段后果驱动？
- 低谷是否来自主角此前选择？
- 高潮是否同时解决外部目标、核心关系与主题？
- 结局是否让观众看到一个与开场不同的新状态？

## 长度

不要用固定页数强制结构，但格式正确的长片通常会形成可读的行业尺度。页数只作生产与阅读参考，不替代戏剧判断。
