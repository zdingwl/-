# Screenplay Studio

真正以“写剧本”为中心的 ChatGPT / Agent Skill。

它不是小说处理器，也不是只会生成大纲的故事工具。最终目标是把创意、故事素材、小说、梗概或已有剧本推进为可以阅读、表演、制作与继续修订的完整影视剧本。

## 三个主入口

1. 原创剧本：从概念、人物、类型或一句话创意开始。
2. 故事转剧本：把小说、故事、真实素材或梗概转换成影视剧本。
3. 剧本重写：对已有剧本做诊断、结构重构、场景重写、对白重写与连续性修复。

小说只是输入来源之一，不是本 Skill 的中心。

## 支持载体

- 电影 / 长片
- 电视剧 / 流媒体剧集
- 短剧 / 微短剧
- 动画剧本

## 核心能力

- Premise / Logline / Story Engine
- 人物目标、需求、错误信念、弧光与关系网
- 结构、序列、节拍、分集与季结构
- 场景目标、阻力、策略、转折、价值变化
- 可见可演动作
- 对白、潜台词、人物声音
- 信息差、秘密、伏笔与回收
- 标准剧本元素与可读性
- Story Bible 与连续性管理
- Script Doctor 与多轮重写

## 与仓库其他 Skill 的关系

- screenplay-studio：通用编剧主系统
- novel-to-screenplay-studio：长小说 / IP 改编专项
- overseas-short-drama-screenwriter：海外短剧市场、本地化与竖屏连续短剧专项

默认情况下，用户说“写剧本”“编剧”“帮我设计一部电影/剧集/短剧”时，应优先使用本 Skill。
