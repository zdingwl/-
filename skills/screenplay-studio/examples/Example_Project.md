# Example Project

## 用户输入

“写一部 8 集犯罪悬疑剧。一个法医发现连续案件的受害者都曾收到自己已故母亲寄出的信。”

## 路由

~~~yaml
mode: original
medium: episodic_series
genre: crime_mystery
episodes: 8
~~~

## Story Contract 示例

~~~yaml
protagonist: 林澈，法医
external_goal: 找出谁在利用母亲身份联系受害者
internal_need: 接受母亲并非自己记忆中的完美受害者
misbelief: 真相只会带来自由
dramatic_question: 她能否在案件真相毁掉家庭记忆前找到凶手
core_relationship: 林澈 / 父亲
opposing_force: 熟悉母亲过去、能操控旧证据的人
story_engine: 每个案件揭开母亲过去的一层，同时让林澈的家庭关系恶化
midpoint_change: 林澈发现母亲当年主动参与过关键事件
climax_choice: 公布能破案但会彻底毁掉母亲名誉的证据
~~~

## 第 1 集职责

- 建立第一封信
- 让林澈产生私人卷入
- 父亲隐瞒一条旧事实
- 集尾确认第二名受害者在死前也收到同样笔迹的信

之后进入 Episode Map → Scene Cards → 完整剧本。
