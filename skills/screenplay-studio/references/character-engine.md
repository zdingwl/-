# Character Engine

## 人物不是资料卡

真正驱动剧情的是：

~~~text
欲望 + 恐惧 + 错误信念 + 资源 + 关系 + 压力下的选择
~~~

## Want / Need / Misbelief

Want：可观察的外部目标。
Need：真正需要完成的内部改变。
Misbelief：限制人物的错误信念。

## Contradiction

好人物通常有真实矛盾，例如：勇敢但害怕亲密；崇尚诚实却靠谎言维持家庭。矛盾必须进入剧情。

## Agency

每阶段检查：
- 他主动做了什么？
- 他选择了什么？
- 选择造成什么后果？
- 下一阶段是否由后果启动？

## Opposing Force

强对手：
1. 有自己的目标。
2. 正确理解一部分现实。
3. 根据主角行为调整策略。
4. 拥有主角缺少的资源。
5. 迫使主角暴露弱点。

## Core Relationship

核心关系应同时存在：双方欲望、双方恐惧、权力结构、未说出口的需求、共同历史、未来不可回避的选择。

关系变化必须可观察：信任、权力、依赖、秘密、边界、身份定义发生改变。

## Character Arc

~~~text
起始信念
→ 压力测试
→ 旧策略短期有效
→ 代价累积
→ 信念危机
→ 不可逆选择
→ 行为证明
~~~

人物弧不能靠“我终于懂了”宣布。

## Voice Fingerprint

人物声音来自教育、职业、阶层、年龄、控制欲、亲密方式、防御方式、幽默、禁忌、说谎方式，而不只是口头禅。
