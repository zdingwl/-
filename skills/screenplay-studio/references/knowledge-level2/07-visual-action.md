# Level 2 — 动作与视觉化（61–70）

## 61. Visible Action

**定义**：观众能直接看到或听到的行为与结果。

**机制**：影视无法直接读取思想，因此关键心理必须落到行为层。

**诊断**：把所有心理词删掉，观众还能理解角色状态吗？

**常见失败**：‘她感到被背叛’‘他意识到一切’直接写在动作行。

**修复**：改成选择、停顿、距离、物件处理、拒绝、撒谎、离开等可演动作。

## 62. Playable Action

**定义**：演员可以执行的具体动作，而非抽象情绪指令。

**机制**：可演动作给表演提供目标，避免动作行替演员解释感受。

**诊断**：演员能否明确做出这句话要求的行为？

**常见失败**：‘更悲伤地’‘感到人生无意义’等不可执行描述。

**修复**：用行为动词和对象改写，如‘他把戒指推回桌中央，不再碰它’。

## 63. Behavioral Detail

**定义**：微小但具体的行为细节揭示状态、关系或习惯。

**机制**：细节让人物有独特性，也能用低成本代替说明。

**诊断**：这个细节是否只属于这个人物/关系，而非任何人都能做？

**常见失败**：随机小动作堆砌；用咬唇、握拳等陈词滥调。

**修复**：选择与职业、习惯、关系债务或当前秘密有关的细节，并让其参与因果。

## 64. Object Dramaturgy

**定义**：让物件承载关系、秘密、资源或选择功能。

**机制**：物件能把抽象冲突变成可见行动，并提供 Setup/Payoff。

**诊断**：某重要物件是否会改变谁能做什么、知道什么或记起什么？

**常见失败**：象征物只用于漂亮意象；拿出又消失。

**修复**：给物件明确拥有者、价值、使用规则与后果，并追踪其状态。

## 65. Spatial Power

**定义**：通过距离、位置、进入/退出权表达关系权力。

**机制**：空间是无需对白就能显示控制与亲密风险的工具。

**诊断**：谁拥有房间中心、出口、门、座位、私人区域？变化了吗？

**常见失败**：所有人物站着说话；空间与冲突无关。

**修复**：设计位置争夺、靠近/退开、阻挡出口、允许/拒绝进入等行为。

## 66. Repetition With Change

**定义**：重复类似行为或场面，通过差异显示人物或关系变化。

**机制**：对照让弧光可见，不需要台词宣布。

**诊断**：是否有一个前后呼应动作，其意义因经历而改变？

**常见失败**：机械重复同一梗；回环只为彩蛋。

**修复**：选一个与核心关系相关的动作，在不同阶段改变执行者、结果或意图。

## 67. Action Consequence

**定义**：动作必须改变局面，而非只增加视觉热闹。

**机制**：有后果的动作才能进入因果链，否则只是装饰。

**诊断**：这段追逐/打斗/仪式结束后，资源、关系、伤势或信息发生什么变化？

**常见失败**：动作场面结束后一切恢复；打斗只为刺激。

**修复**：让动作造成不可忽略的损失、暴露、资源转移或关系后果。

## 68. Visual Setup

**定义**：前文通过可见元素建立后文可回收的功能。

**机制**：视觉 Setup 让 Payoff 感到既意外又必然。

**诊断**：后文关键解决方案是否曾被公平展示但未被过度强调？

**常见失败**：高潮突然出现新道具；或 Setup 被镜头/文字硬加粗。

**修复**：自然嵌入日常使用，确保早期有功能，后期获得第二层意义。

## 69. Contrast Scene

**定义**：通过相邻或镜像场景的行为差异放大人物、关系或主题。

**机制**：对比能让观众自己得出结论，减少解释。

**诊断**：两场并排时，是否能看到同一问题的不同处理方式？

**常见失败**：对比只是视觉色调；与人物决策无关。

**修复**：围绕同一价值问题设计不同角色/不同阶段的两种选择，并展示结果差异。

## 70. Production Awareness

**定义**：在不牺牲故事的前提下理解场面规模、地点与可执行性。

**机制**：剧本是合作蓝图；无意义的复杂度会吞噬预算和注意力。

**诊断**：昂贵场面是否同时承担关键人物/因果功能？

**常见失败**：为了‘电影感’不断换地点、加群众、爆炸。

**修复**：优先保留高戏剧价值的复杂场面，合并低功能地点，并让规模变化服务故事升级。
