# Screenplay Format

## 原则

格式的目标是让阅读、表演、制片与后续拆解清晰。

本 Skill 默认生成可读的 Submission / Spec Script 风格文本，不默认生成 Shooting Script。

默认不主动加入：
- 场号
- 镜头编号
- 摄影机位置
- 焦段
- 连续大量 CUT TO
- 制片调度备注

除非用户明确要求。

## 常用元素

### Scene Heading

~~~text
INT. 地点 - DAY
EXT. 地点 - NIGHT
~~~

### Action

只描述观众可以看到或听到的内容，优先当前时态、短段落和具体动词。

### Character / Dialogue

角色名在对白之前。对白只写角色实际说出的内容。

### Parenthetical

只在语义容易误读、对象不清或必要行为提示时使用，不替演员逐句规定情绪。

### Transition

仅在叙事确实需要特定转场效果时使用。

## Master Scene

Submission Draft 优先以场景为单位，用 Scene Heading、Action、Character、Dialogue 完成叙事，不把剧本写成导演分镜。

## Scene Numbers

普通投稿 / 早期创作稿默认不需要场号；制作稿阶段才可能需要稳定场号。

## Camera Directions

默认避免大量 CLOSE UP、PAN TO、WE SEE、CAMERA PUSHES、镜头焦段等。只有镜头本身对理解剧情不可替代，或用户明确要求导演稿时使用。

## Readability

动作段落避免小说式“墙”：
- 一个动作单元一个短段
- 重要变化单独成行
- 少用抽象形容
- 少写不可拍心理
- 大写强调谨慎使用

## 中文输出示例

~~~text
INT. 公寓客厅 - NIGHT

林乔把钥匙放在桌上，没有脱外套。

周野
你今天回来得真早。

林乔看向餐桌。两副碗筷。

林乔
第三副呢？
~~~

## 行业参考

Academy Nicholl 官方 Screenwriting Resources 说明：专业剧本存在细节差异，但 submission script 通常没有场号、很少指定摄影机镜头，并使用 master scenes。

Academy Nicholl 当前申请规则以 standard industry format 与 12-point Courier 为长片提交基准。

Final Draft 官方资料将 Scene Heading、Action、Character、Dialogue、Parenthetical、Transition 作为主要剧本元素。

这些来源用于确认专业格式共识，不把任何单一软件习惯视为创作教条。
