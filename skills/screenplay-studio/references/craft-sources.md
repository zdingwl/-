# Craft Sources

本 Skill 的方法体系综合常见编剧框架与仍可核验的行业格式资料。方法只作为诊断工具，不作为唯一真理。

## 官方 / 行业格式参考

1. Academy of Motion Picture Arts and Sciences — Nicholl Screenwriting Resources
   - https://www.oscars.org/nicholl/screenwriting-resources
   - 用途：Submission script、Master Scene、场号与摄影指令边界。

2. Academy Nicholl — How to Apply
   - https://www.oscars.org/nicholl/about
   - 用途：当前长片提交的 standard industry format 与 12-point Courier 基准。

3. Final Draft — Screenplay Formatting and Elements
   - https://www.finaldraft.com/learn/screenplay-formatting-elements/
   - 用途：Scene Heading、Action、Character、Dialogue、Parenthetical、Transition 等主要元素。

## 方法论使用原则

- 三幕、五幕、Sequence、七点、英雄旅程、Save the Cat 等都只是观察框架。
- 不用固定页码或固定分钟数替代剧情判断。
- 不把“一页一分钟”当精确生产公式。
- 不因为某个方法有固定节点，就为了填节点制造无因果事件。
- 不同模型冲突时，优先检查人物目标、因果、选择、代价与后果。
