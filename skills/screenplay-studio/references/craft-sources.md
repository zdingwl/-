# Craft Sources

本 Skill 区分两类来源：

1. Skill 工程与结构：优先参考 OpenAI 官方 Skills 文档。
2. 编剧方法与格式：优先参考行业/专业写作资料；方法只作为诊断工具，不作为唯一真理。

https://openai.com/academy/skills/

用途：

- supporting resources 承载模板与参考资料

https://developers.openai.com/api/docs/guides/tools-skills

## 剧本格式

### Academy Nicholl — Screenwriting Resources

https://www.oscars.org/nicholl/screenwriting-resources

用途：

- Submission script / master scene 基准
- 一般不使用场号
- 少写不必要的摄影机 shot designation
- 专业剧本存在细节差异，不应把某一种版式当绝对唯一标准

### Academy Nicholl — How to Apply / Reader Criteria

https://www.oscars.org/nicholl/about

用途：

- 行业格式参考
- Story / Voice / Characters / Craft / Meaning 等阅读维度
- 主角行动、冲突推进、人物声音与可读性

### Final Draft — Screenplay Formatting Elements

https://www.finaldraft.com/learn/screenplay-formatting-elements/

用途：

- Scene Heading
- Action
- Character
- Dialogue
- Parenthetical
- Transition
- 动作行简洁与可读性

## 场景、对白、改编

### John August — How to write a scene

https://johnaugust.com/2007/write-scene

用途：

- 场景写作前明确需要发生什么
- 先在“屏幕上”想象可见行为
- 场景并非靠解释成立

### John August — How to write dialogue

https://johnaugust.com/2007/how-to-write-dialogue

用途：

- 对白先处理流动、控制权与信息交换
- 人物需要互相听和反应，而不是轮流说作者台词

### John August — The essentials of adaptation

https://johnaugust.com/2003/the-essentials-of-adaptation

用途：

- 小说的内心洞察需要转化为可见可听的影视表达
- 改编常常需要重新思考结构、故事线和人物

### John August — Script adaptations

https://johnaugust.com/2003/script-adaptations

用途：

- 改编应先把素材当成电影/剧集问题处理
- 从真正需要的元素重新“搭建”，而不是只从原作里向下删减

## 方法论使用原则

- 三幕、五幕、Sequence、七点、英雄旅程、Save the Cat 等只作为观察与诊断框架。
- 不用固定页码或固定分钟数替代剧情判断。
- “一页约一分钟”只能作为粗略生产参考，不是戏剧规则。
- 不为填结构节点制造无因果事件。
- 当不同框架冲突时，优先检查人物目标、因果、选择、代价、关系与后果。
