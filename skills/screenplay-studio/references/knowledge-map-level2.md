# Screenplay Knowledge Map — Level 2

Level 1（`knowledge-map-120.md`）回答“要检查什么”。

Level 2 回答：

- 这个知识点为什么有效？
- 它在戏剧系统里和哪些上游/下游变量相连？
- 怎么判断当前剧本真的有问题？
- 常见的伪解决方案是什么？
- 应该修改哪个结构变量，而不是只修表面？

## 深度条目结构

每个知识点都包含：

- **定义**：准确界定概念。
- **机制**：它为什么会影响观众体验与剧情因果。
- **诊断**：从现有文本如何判断。
- **常见失败**：最容易出现的假完成。
- **修复**：优先改变哪个变量。

## 根因优先

如果一个问题同时命中多个条目，按上游优先：

~~~text
Premise / Story Engine
→ Character Agency / Opposition / Stakes
→ Causality / Structure
→ Sequence / Episode
→ Scene
→ Information
→ Dialogue / Visual Action
→ Format
~~~

不要在上游坏掉时先润色下游。
