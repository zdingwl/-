# Story & Structure Engine

## 结构的本质

结构不是节点表，而是压力系统。有效结构持续做四件事：明确人物目标、增加阻力与代价、迫使新选择、让选择产生后果。

## Story Engine

~~~text
人物欲望 × 持续阻碍 × 关系冲突 × 信息不对称 × 选择后果
= 可持续故事发动机
~~~

测试：
- 如果误会现在说开，故事是否立刻结束？
- 如果秘密现在揭开，还有真实冲突吗？
- 对手是否会根据主角行动改变策略？
- 主角成功一次后，会不会制造更大的问题？
- 下一步来自前一步后果，还是作者随机添加？

## Premise / Dramatic Question / Theme Question

Premise 至少包含：谁、想要什么、被什么阻止、失败会失去什么、冲突为什么独特。

Dramatic Question 必须能由结局回答。

Theme Question 优先写成价值冲突，例如“忠诚什么时候变成共犯？”高潮用人物选择回答。

## Causality

重大节点优先：

~~~text
因为 A → 所以 B → 但是 C → 因此 D
~~~

警惕只用“然后”连接的事件。

## Turning Point

有效转折至少改变一项：目标、风险、权力、信息意义、关系、资源、时间压力、道德代价或观众预期。

## Midpoint

中段至少完成一种功能：
- 假胜利 / 假失败
- 目标升级
- 新真相改变旧信息意义
- 权力逆转
- 游戏规则改变
- 被动转主动
- 外部目标与内部需求正面冲突

## Low Point

低谷优先来自前文选择累积的代价，而非随机灾难。

## Climax

高潮必须汇合主要冲突、迫使最高代价选择、让主角无法同时保住所有东西，并用行动证明人物弧。

## Ending State

结局检查三条线：
1. 外部目标。
2. 核心关系。
3. 主角价值观 / 错误信念。

结构模板只作诊断，不先填节点再硬塞剧情。
