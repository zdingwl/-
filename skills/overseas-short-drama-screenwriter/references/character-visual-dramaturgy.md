# 人物弧光与视觉戏剧化

本文件用于所有创作模式，不属于爽剧专用规则。

目的：把“人物设定、人物心理、人物成长”真正转换成可见、可演、可推动剧情的戏剧行为。

方法参考并重新整理自多套公开编剧资料，其中包括 @山音 的《山音超级编剧大师》公开项目。这里只吸收通用编剧思想，不复制其原始文本、模板或完整工作流。

---

# 一、人物不是标签，而是选择系统

不要停留在：

```text
坚强
善良
聪明
冷酷
独立
```

主要人物至少明确：

```yaml
人物内核:
  外在目标:
  内在需求:
  错误信念:
  错误信念曾经保护过他什么:
  现在为什么开始伤害他:
  最害怕失去什么:
  最想被谁认可:
  自称绝不会做什么:
  在什么压力下可能越线:
  结尾需要证明的变化:
```

外在目标推动事件。

内在需求推动人物弧。

错误信念决定人物为什么会做出“合理但有代价”的选择。

---

# 二、人物弧必须通过行为证明

人物弧不是：

> 她从不自信变得自信。

而是：

```text
开篇遇到同类压力时，她选择逃避。
↓
中段遇到更高代价时，她开始尝试承担。
↓
高潮面对最大损失时，她做出开篇绝不会做的选择。
```

建立人物弧证明表：

```yaml
人物弧:
  开篇压力:
  开篇选择:
  中段类似压力:
  中段选择:
  高潮最大压力:
  高潮选择:
  变化证明:
```

高潮的价值之一，是证明人物到底有没有变化。

---

# 三、心理必须优先转换成可见行为

剧本不要依赖小说式心理解释。

遇到以下表达时优先重写：

```text
她意识到……
他觉得……
她心里很难过……
他终于明白……
她非常愤怒……
他陷入回忆……
```

优先转换为：

- 选择
- 动作
- 停顿
- 回避
- 视线
- 距离
- 物件处理
- 谁先离开
- 谁拒绝回答
- 谁改变称呼
- 谁交出或收回某件东西
- 人物采取的新策略

原则：

> 内心变化如果重要，就让它改变人物下一步行为。

---

# 四、视觉动作必须承担剧情意义

不要为了“有画面”塞无意义动作。

有效视觉动作应该至少完成一种功能：

```text
改变权力
暴露信息
隐藏信息
改变关系
制造代价
做出选择
回收伏笔
形成记忆点
```

例如：

```text
摘下戒指
```

只有当它意味着关系状态发生变化时才有价值。

如果只是装饰性动作，不必强行写。

---

# 五、场景权力变化

场景开始前先问：

```text
谁占优势？
优势来自什么？
```

优势可以来自：

- 信息
- 金钱
- 法律权利
- 身份
- 职位
- 情感依赖
- 证据
- 时间
- 空间
- 人数
- 秘密
- 道德立场

场景结束再问：

```text
谁占优势？
为什么发生变化？
变化会迫使谁下一步行动？
```

场景任务卡建议追加：

```yaml
权力变化:
  场景前优势方:
  优势来源:
  第一次出招:
  对方反制:
  权力转折:
  场景后优势方:
  不可逆后果:
```

并非每场都必须“翻盘”，但重要场景应有权力、关系、信息、风险或认知的移动。

---

# 六、人物说什么不等于人物想什么

重要场景同时追踪：

```yaml
人物场景状态:
  表面目标:
  真正目标:
  不愿说出口的内容:
  最怕对方发现的内容:
  当前策略:
  策略失败后的第二策略:
```

这样潜台词才来自人物目标，而不是为了显得高级而故意说谜语。

---

# 七、人物关系必须有权力来源

核心关系不要只写“相爱 / 仇恨 / 好友 / 父女”。

记录：

```yaml
关系权力:
  A需要B什么:
  B需要A什么:
  A能失去什么:
  B能失去什么:
  A掌握什么资源或秘密:
  B掌握什么资源或秘密:
  当前更依赖对方的是谁:
  当前更有离开能力的是谁:
```

关系戏真正有变化时，往往是这些答案发生了变化。

---

# 八、多线故事必须互相造成后果

多线项目可以存在：

```text
主剧情线
关系线
秘密 / 调查线
家庭线
事业线
```

但不要把它们写成彼此无关的小故事。

至少检查：

```text
A线的选择是否改变B线？
B线获得的信息是否改变主线？
关系变化是否会改变人物处理外部目标的方式？
秘密揭露是否会改变人物关系？
```

如果一条支线长期可以整段删除而主线毫无变化，它可能不是有效故事线。

---

# 九、人物弧与类型模式的关系

不同类型不需要同样强度的人物弧。

## 高爽商业

人物弧可以表现为：

- 从被动到掌控
- 从求认可到自我定义
- 从依赖到主动选择

但不能为了“成长”拖慢核心类型回报。

## 情感 / 爱情

人物弧通常直接决定关系能否成立。

重点看：

- 能否停止旧有防御机制
- 能否承担亲密关系的代价
- 能否做出以前不会做的关系选择

## 悬疑 / 惊悚

人物弧可以与认知变化绑定：

```text
相信某件事
→ 证据动摇
→ 重新解释世界
→ 最终选择
```

## 喜剧

人物缺陷往往是笑料发动机。

角色可以成长，但不能太快治好自己的“喜剧缺陷”，否则喜剧发动机会失压。

## 慢燃 / 文艺

人物弧可以细微，但必须可观察。

变化可能只是：

- 第一次愿意说真话
- 第一次没有逃走
- 第一次允许另一个人进入自己的空间

---

# 十、终审问题

写完一个阶段后检查：

```text
□ 主要人物有明确外在目标
□ 主要人物有内在需求或人物缺口
□ 错误信念会真实影响选择
□ 人物弧通过行为而不是旁白证明
□ 重要心理变化被转换成可见行为
□ 关键场景存在权力 / 关系 / 信息 / 风险移动
□ 关系双方都有自己的资源与软肋
□ 多条故事线互相制造后果
□ 高潮选择回应了人物开篇状态
□ 没有为了人物弧牺牲类型承诺
```

核心原则：

> 人物不是“被作者描述成什么样”，而是“在有代价的选择里证明自己是什么样”。
