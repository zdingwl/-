# 追剧欲与观众观看驱动力

本文件用于所有短剧类型。

它解决的核心问题不是“剧本有没有写完整”，而是：

> 观众为什么现在还不退出？为什么看完这一集还想继续点下一集？

剧本可以逻辑正确、人物完整、格式规范，却依然没有追看欲。因此，观看驱动力必须作为独立设计层，不能只依赖开场钩子、反转或集尾悬念。

本模块吸收公开短篇爽文、短剧与通用叙事研究中可迁移的方法，只提取底层机制，不复制任何具体作品的人物、情节、台词或独特反转。

---

## 一、追剧欲的三层核心

任何阶段都要知道三件事：

```text
观众现在站谁？
观众现在最想知道什么？
观众现在最期待什么发生？
```

三者分别对应：

```text
情绪站队
+
观众问题链
+
终局期待 / 阶段期待
```

不要求三项每时每刻都同样强，但核心段落至少应有两项明确成立。

如果观众既不在乎谁输谁赢，也没有想知道的问题，也没有期待的未来事件，故事即使逻辑完整，也缺乏追看动力。

---

## 二、核心推进循环

```text
建立问题 / 欲望 / 不公平 / 危险
→ 让人物采取行动
→ 给观众部分答案或阶段回报
→ 回报产生后果
→ 旧问题升级、改写或转化
→ 形成新的更具体观看理由
```

核心不是“一直不回答”，而是：

> 一边回答，一边生成价值更高的新问题。

弱循环：

```text
提问
→ 拖延
→ 差点回答
→ 再拖延
```

强循环：

```text
提问
→ 部分回答
→ 旧认知被修正
→ 人物做出选择
→ 产生新后果
→ 更大的问题自然出现
```

---

## 三、情绪站队：先让观众在乎，再让观众等待

尤其在高爽、情感、爱情、家庭、职场和复仇类型中，观众只有先完成情绪站队，后续回报才有重量。

开局或重要阶段检查：

```yaml
情绪站队:
  观众当前最支持谁:
  观众当前最反感谁或什么行为:
  观众认为哪件事最不公平:
  观众最希望谁后悔:
  观众最希望主角夺回什么:
  哪个关系态度发生改变会最有情绪价值:
```

注意：

- “反派很坏”不等于观众已经站队。
- 观众要看见具体行为、具体损失和具体关系后果。
- 不要用长篇解释要求观众同情人物，要通过事件让观众自己形成判断。

高爽模式可把情绪站队与 `satisfaction-engine.md` 的爽点债务联动。

---

## 四、八类主要观看驱动力

一部强短剧通常同时使用两种以上：

1. **好奇**：真相是什么？身份是什么？为什么会这样？谁在撒谎？
2. **期待**：观众大致知道某件事会发生，但想看它怎样发生。
3. **情绪债务**：前面制造了不公、伤害、失去或羞辱，后面需要对应回报。
4. **关系欲望**：会不会在一起、决裂、背叛、和解、选择彼此、权力翻转。
5. **危险**：某个具体风险正在逼近，人物是否能避开或承受。
6. **选择压力**：人物必须在两个都有代价的选项中决定。
7. **认知翻转**：新信息让已经知道的事实获得新的解释。
8. **升级预期**：一个问题解决后，解决本身制造更大的问题。

不能只靠一种驱动力连续几十集。

---

## 五、未知悬念与“等他知道”的预期悬念要同时管理

短剧不只有“观众不知道答案”的悬念。

还存在另一种很强的驱动力：

> 观众已经知道答案，但剧中某个人不知道，观众在等待他知道时会发生什么。

因此关键秘密至少维护：

```yaml
信息差:
  观众知道:
  主角知道:
  对手知道:
  关键配角知道:
  谁还不知道:
  观众正在等待谁知道:
  一旦知道会改变什么:
```

两类体验：

```text
未知型：到底是什么？
预期型：他什么时候知道？知道以后会怎样？
```

悬疑更常依赖未知型；身份翻转、爱情、复仇、家庭和职场题材常可大量使用预期型。

---

## 六、每集维护“观众问题链”

```yaml
观众问题链:
  开集最大问题:
  当前最期待的事件:
  当前最担心的后果:
  当前情绪站队:
  本集新增猜测:
  本集确认:
  本集推翻:
  本集部分回答:
  本集故意延迟回答:
  延迟时提供的新价值:
  集尾最大问题:
  下一集必须提供的新价值:
```

每次延迟答案，都必须用至少一种东西补偿：

- 新信息
- 人物选择
- 关系变化
- 风险升级
- 阶段回报
- 新证据
- 新代价
- 新的更具体问题

如果只是“再等一集告诉你”，属于拖延，不属于有效悬念。

---

## 七、建立终局期待，而不是只有结局

“知道故事最后会结束”不等于“期待结局”。

需要尽早建立至少一个观众真正想看到的未来画面。

```yaml
终局期待:
  观众最想看到的最终画面:
  最想看到谁后悔或改变:
  最想看到什么真相公开:
  最想看到哪段关系发生最终选择:
  最想看到主角夺回 / 放下 / 完成什么:
```

不同类型的终局期待不同：

- 高爽：夺回、昭雪、翻盘、清算、真正掌控。
- 悬疑：真相闭合、凶手/秘密揭晓、核心认知被重构。
- 爱情：两个人最终如何选择彼此或选择分开。
- 情感：关系是否修复、切断、原谅、理解或重新定义。
- 喜剧：人物错误欲望最终会造成怎样的终极后果或成长。
- 惊悚：能否活下来、逃出去、识破威胁或付出什么代价。
- 慢燃：人物最终是否成为开篇时做不到的那种人。

终局方向可以让观众大致猜到，但具体到达方式不能过于显然。

---

## 八、大方向可以期待，具体兑现方式不要轻易猜中

“可预测性”不是越低越好。

观众需要期待，也需要惊喜。

因此使用：

```text
终点可期待
+
路径有变化
+
人物选择有代价
```

每个阶段问：

```text
普通观众看到当前信息后，最容易预测下一步是什么？
这个预测本身是否就是我们希望建立的期待？
如果是，具体兑现方式有没有新意？
如果不是，是否应该通过人物选择、代价、信息意义或关系后果改变路线？
```

不要为了不可预测随机加反转。

优先改变：

- 人物做什么选择
- 选择要付什么代价
- 已知信息真正意味着什么
- 成功以后失去什么
- 对手如何适应
- 哪段关系因此改变

强反转应尽量做到：

> 第一次看意外，回头看合理。

---

## 九、小兑现不能让故事泄气，要制造新后果

阶段回报不应该只是“终于爽了，然后继续下一个无关事件”。

优先设计：

```text
兑现旧承诺
→ 改变权力 / 关系 / 信息 / 资源
→ 产生新的代价或更高层问题
→ 下一轮故事被启动
```

例如：

```text
主角证明自己没有偷方案
→ 清白拿回
→ 但客户仍选择真正偷方案的人
→ 问题从“证明清白”升级为“夺回实际利益”
```

原则：

> 回报既要让观众得到满足，也要让故事继续向前。

高爽模式尤其要避免“打脸结束、世界归零、下一集重新找人欺负主角”。

---

## 十、熟悉世界 + 一个异常变量

短剧开局理解成本要低。

优先从观众容易理解的现实关系、职业、家庭或社会场景进入，再加入一个能立刻改变关系的异常变量。

```text
熟悉世界
+
异常人物 / 秘密 / 关系 / 事件
=
低理解成本 + 高问题密度
```

例如只是结构示意：

```text
普通婚姻 + 配偶隐藏的第二身份
普通职场 + 被偷走的关键成果
普通家庭 + 遗嘱中完全异常的安排
普通学校 + 某个学生拥有不应存在的记录
```

不要为了“高概念”让观众先学习大量世界观才能理解第一集。

奇幻、狼人、科幻等类型也应尽量用一个清晰人物处境进入世界，而不是先讲规则百科。

---

## 十一、用“主观进入”替代大段背景介绍

小说常用第一人称快速建立代入；影视短剧不必因此堆旁白。

应吸收的是背后的原则：

> 让观众尽快从一个具体人物的处境进入故事，而不是站在上帝视角听作者介绍世界。

弱：

```text
这是一个拥有三代产业的复杂家族，父亲有三个孩子……
```

强：

```text
主角推开病房门。
律师已经在里面。
桌上的遗嘱没有主角的名字。
```

通过人物看见异常、承受后果、做出选择来介绍世界。

旁白只有在确实属于作品风格和类型需要时才使用，不作为默认补信息工具。

---

## 十二、集尾必须有“下一集理由”

允许的集尾驱动力包括：

- **问题型**：刚出现一个更具体、更重要的问题。
- **危险型**：某个风险已经真正启动。
- **选择型**：人物必须马上作出有代价的决定。
- **情绪型**：前面的情绪债务进入必须回应的节点。
- **关系型**：关系发生实质变化，但后果还没有完成。
- **行动型**：主角做出不可撤回的决定，下一集必须看到后果。
- **预期型**：某个不知道真相的人即将碰到真相。

不要求每集突然切黑。

强集尾的判断是：

> 下一集已经被这一集的后果启动。

---

## 十三、不同类型的追剧欲来源不同

### 高爽
情绪站队 + 情绪债务 + 反击期待 + 权力变化 + 更高层对手。

### 悬疑
问题链 + 公平线索 + 假设更新 + 未知悬念 + 危险。

### 爱情 / 情感
关系期待 + 未说出口的需求 + 信息差 + 选择代价 + 关系位置变化。

### 喜剧
人物错误策略 + 观众预知后果 + 后果升级 + 更糟的新选择。

### 高压 / 惊悚
危险 + 信息差 + 时间或空间限制 + 生存选择。

### 慢燃 / 文艺
不要求强悬崖，重点是人物、关系、认知、未完成情绪和未来选择持续变化。

不能拿爽剧的“打脸期待”检查所有类型。

---

## 十四、前 3 集试播门槛【核心门槛】

长剧正式进入大批量逐集正文前，优先完成前 3 集完整样稿。

然后检查：

```text
看完第1集，观众站队了吗？
看完第1集，是否存在明确进入第2集的理由？
看完第2集，是否获得新价值，而不只是继续拖第1集的问题？
看完第3集，故事是否已经证明有持续发动机？
当前是否存在至少两个有效观看驱动力？
是否已经形成一个阶段期待或终局期待？
如果完全不知道后续大纲，只看这3集，会不会自然想知道第4集发生什么？
```

如果只能得到：

```text
逻辑完整
人物清楚
铺垫充分
```

但没有明确的“还想继续”，试播不通过。

优先返回修改：

- 开局异常变量
- 主角欲望
- 情绪站队
- 核心关系
- 第一阶段秘密
- 信息差
- 选择代价
- 第一次重要回报
- 终局期待

不要继续批量写后续几十集。

---

## 十五、每集三问 + 单集诊断

每集完成后先回答三个最重要的问题：

```text
我现在站谁？
我现在最想知道什么？
我现在最期待什么发生？
```

再检查：

```text
1. 这一集最核心的观众问题是什么？
2. 这一集给了什么新价值？
3. 哪个旧问题得到推进、部分回答或重新解释？
4. 哪个情绪债务、关系期待或危险得到推进？
5. 人物做了什么会制造下一集后果的决定？
6. 集尾的具体承接理由是什么？
7. 去掉“切黑”，这一集本身是否仍产生真正后果？
8. 下一集如果只是按最显然的路线发展，会不会太好猜？
```

如果第6项回答不出来，优先重写集尾前的因果，而不是随便加一句神秘台词。

---

## 十六、常见失败

- 只有钩子，没有真正的故事发动机。
- 只有悬念，没有新价值。
- 事件很多，但观众不知道自己在期待什么。
- 观众没有完成情绪站队。
- 为了意外而强行反转。
- 所有剧情都按最显然的路线发生。
- 只建立痛苦，不提供阶段回报。
- 回报之后世界归零，没有产生后果。
- 所有人都在等待，没人主动制造后果。
- 关系反复拉扯，但位置没有实质变化。
- 秘密只靠“差点说出来又被打断”续命。
- 所有集尾都使用同一种套路。
- 只知道最终结局，却没有观众真正期待的终局画面。
- 开头用大量世界观、家族史或人物履历代替主观进入。

---

## 十七、完成标准

进入大规模逐集写作前确认：

```text
□ 情绪站队明确，或当前类型有等价的情感投入机制
□ 核心观众问题明确
□ 至少两类主要观看驱动力可以持续工作
□ 已建立阶段期待或终局期待
□ 每个阶段知道观众最想看到什么发生
□ 未知悬念与预期型悬念按需管理
□ 延迟答案时持续提供新价值
□ 重要问题有阶段性回答，不无限拖欠
□ 小兑现会改变局势并产生新后果
□ 人物选择不断制造下一步因果
□ 已做可预测性检查
□ 大方向有期待，具体兑现方式不过分显然
□ 集尾承接理由来自本集因果
□ 不机械依赖悬崖式结尾
□ 开局尽量通过人物主观处境进入，而不是大段背景介绍
□ 前3集样稿能够独立产生自然的继续观看动力
```

核心原则：

> 好短剧不是让观众知道“后面还有剧情”，而是让观众心里有一件还没放下的事。

> 观众既要不断得到东西，又要不断产生新的期待。
