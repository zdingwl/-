# 短剧媒介转换与专用编剧规则

本文件用于把通用电影、电视剧、小说编剧方法，转换成适合竖屏短剧 / 微短剧的实际写法。

它不是某一种类型的规则。爽剧、悬疑、爱情、情感、喜剧、惊悚、慢燃都可以使用本模块。

核心原则：

> 短剧不是把电影压短，也不是把电视剧切碎。
>
> 短剧的核心差异，是单位时间内必须发生更高密度的有效变化，同时保持因果、人物和情绪成立。

---

# 一、短剧与电影、电视剧的结构差异

电影通常以整部作品完成一个大型人物弧和完整结构。

传统电视剧通常同时维护：

```text
季主线
+ 单集故事
+ 人物支线
```

竖屏短剧更强调：

```text
全剧主线
↓
阶段目标
↓
单集微型戏剧单元
↓
场景内部变化
```

因此不能直接：

```text
90分钟电影大纲
÷ 60
= 60集短剧
```

也不能：

```text
45分钟电视剧一集
切成20段
= 20集短剧
```

必须重新设计每集职责、信息释放、情绪回报和承接。

---

# 二、短剧的基本单位是“有效变化”

短剧节奏快，不等于台词快、人物一直吵架、每隔固定秒数反转。

真正的快，是单位时间内发生了有效变化。

有效变化包括：

```text
目标变化
关系变化
权力变化
风险变化
信息变化
认知变化
人物选择变化
资源变化
秘密状态变化
观众预期变化
类型回报
```

如果一段戏只是重复背景、重复争吵、重复误会，而没有任何状态改变，即使台词很多，也属于慢。

---

# 三、单集必须是一个微型戏剧单元

单集不要求每次完整走一遍传统三幕，但至少要有：

```text
当前问题
→ 人物行动
→ 阻力 / 反制
→ 局面变化
→ 新后果或新问题
```

单集可以没有“大反转”，但不能没有“变化”。

不同类型的变化不同：

- 高爽：反击、获得、权力变化、阶段兑现
- 悬疑：线索、反证、新嫌疑、认知翻转、风险升级
- 爱情：靠近、疏远、选择、信任、吸引与阻碍变化
- 情感：关系位置、理解、误解、牺牲、边界变化
- 喜剧：错误策略、后果升级、处境翻转
- 惊悚：安全感下降、威胁升级、逃生策略变化
- 慢燃：人物理解、自我认知、关系距离、价值判断变化

---

# 四、开场要快进入“当前问题”

短剧开场不等于必须爆炸、打架、吵架。

真正应该尽快让观众知道：

```text
现在发生了什么？
谁想得到什么？
为什么现在必须处理？
不处理会怎样？
```

优先从冲突已经形成、决定即将发生、秘密即将暴露或关系已经失衡的时刻进入。

减少：

- 长时间环境介绍
- 人物起床、洗脸、出门等无戏过程
- 先介绍所有人物再开始故事
- 大段旁白解释世界观
- 角色互相讲双方都知道的背景

---

# 五、场景必须短而完整，不是短而碎

短剧场景通常更集中，但不能变成没有因果的碎片。

每场尽量完成至少一个核心任务，并最好兼顾第二任务：

```text
推进剧情 + 改变关系
给出信息 + 制造新问题
证明人物 + 改变权力
回收伏笔 + 推动下一步行动
制造类型回报 + 产生新代价
```

场景结束时优先出现：

- 结果
- 决定
- 暴露
- 失去
- 获得
- 新行动
- 新危险
- 新关系位置

不要场景结束后再用对白总结刚才发生了什么。

---

# 六、信息密度高，但不能信息过载

短剧需要高信息密度，不等于每句台词都塞设定。

优先把信息放进：

- 争夺
- 证据
- 交易
- 选择
- 指责
- 防御
- 物件
- 公开后果
- 人物错误判断

避免：

```text
人物A：我们十年前因为父亲去世搬到纽约，你还记得吗？
```

优先：

```text
人物A：你爸留下的房子，你卖了。
人物B：不卖，我们连纽约都到不了。
```

信息进入冲突，而不是脱离冲突讲解。

---

# 七、短剧人物必须“快速可识别，长期可变化”

前几集要尽快让观众知道主要人物：

```text
想要什么
害怕什么
跟谁冲突
有什么反差
为什么值得继续看
```

但不能因此把人物写成标签。

人物仍然必须维护：

- 外在目标
- 内在需求
- 错误信念
- 压力选择
- 人物弧

区别只是：证明这些东西的场景更经济。

优先用一个有代价的动作，同时证明多项人物信息。

---

# 八、尾钩不是强行切断

短剧集尾通常需要强承接，但承接必须来自本集因果。

好的尾钩：

```text
本集行动
→ 产生后果
→ 后果制造下一集问题
```

弱尾钩：

```text
人物刚要说答案
→ 突然切黑
```

如果连续多集都靠“说到一半切断、门突然打开、电话突然响、神秘人出现”制造悬念，会迅速模板化。

尾钩可以是：

- 新决定
- 新发现
- 新代价
- 新威胁
- 新关系变化
- 新身份信息
- 新证据
- 观众比人物多知道一步
- 人物做出不可逆选择

---

# 九、单集时长不能变成机械秒表

单集时长影响结构，但不能用固定秒数代替戏剧判断。

可以内部参考：

```text
开头尽快进入问题
中段持续升级或变化
后段产生结果 / 回报 / 新后果
结尾建立下一问题
```

禁止把以下写成普遍硬规则：

- 每10秒必须反转
- 每30秒必须一个钩子
- 每集固定3场
- 每集固定3个爽点
- 每集固定多少字

真正检查的是：

> 在用户指定时长内，有没有持续有效变化，是否存在明显可删的空转段落。

---

# 十、竖屏观看环境影响场景设计

本 Skill 仍只负责剧本，不写分镜、景别和运镜。

但剧本层需要考虑移动端观看特点：

- 核心冲突尽量集中在人和关系上
- 重要动作尽量清楚、简单、可识别
- 关键物件应具有明确剧情意义
- 避免必须依赖复杂空间调度才能理解的核心信息
- 避免大量远距离群像才能成立的戏剧信息
- 重要变化应能通过人物行为、关系位置、物件和结果被理解

这些是剧本可读性与媒介适配，不是分镜指令。

---

# 十一、短剧对白需要更高行动密度

短剧对白不是单纯更短，而是更少“无功能句”。

重要对白至少服务一个行动目的：

```text
试探
逼迫
隐瞒
攻击
说服
拒绝
交易
转移
诱导
争夺定义权
改变关系
```

可以短，也可以在关键情绪场景稍长。

判断标准不是字数，而是：

> 这句话如果删掉，人物策略、信息、关系或情绪是否受影响？

---

# 十二、短剧允许慢燃，但必须有微变化

慢燃短剧不是不能存在。

慢燃模式可以：

- 少大事件
- 少硬反转
- 情绪积累更长
- 对白更克制
- 留白更多

但每场仍需改变至少一项：

```text
理解
关系距离
信任
选择可能性
自我认知
风险感知
价值判断
```

如果连续多个场景只是氛围重复，没有任何微变化，仍然属于拖。

---

# 十三、短剧改编必须重新切分戏剧单元

小说、电影、电视剧改编成短剧时，不能按原章节、原场次或原分钟数直接切。

正确顺序：

```text
识别核心冲突与观众承诺
→ 提取关键因果链
→ 找出每个阶段的状态变化
→ 重排信息与秘密
→ 重新设计单集问题与承接
→ 再划分单集
```

每一集的边界应该落在“局势发生变化”的地方，而不是机械字数边界。

---

# 十四、短剧专用单集检查

每集完成后检查：

```text
□ 前段是否迅速建立当前问题
□ 主角或核心人物是否采取行动
□ 是否出现有效阻力或反制
□ 单集是否至少有一次明显状态变化
□ 是否存在可以整段删除却毫无影响的内容
□ 信息是否进入冲突，而不是独立讲解
□ 关系、权力、风险、认知、资源或目标是否至少改变一项
□ 类型承诺是否获得推进或回报
□ 集尾是否来自本集后果
□ 下一集是否有明确承接问题
```

不要求每项都靠大反转完成。

---

# 十五、短剧专用场景检查

每场完成后问：

```text
谁在争取什么？
对方怎么阻止？
人物有没有改变策略？
场景前后谁掌握更多信息或控制权？
发生了什么不可忽略的变化？
为什么下一场必须发生？
```

如果回答不出来，优先删除、合并或重写。

# 十六、与其他模块的关系

本模块位于：

```text
通用编剧理论
↓
人物 / 冲突 / 结构 / 场景 / 潜台词
↓
短剧媒介转换（本文件）
↓
类型专项规则
↓
逐集完整短剧剧本
```

按需组合：

- 高爽：本文件 + `satisfaction-engine.md`
- 悬疑：本文件 + 信息不对称 / 线索规则
- 情感 / 爱情：本文件 + 人物弧与关系规则
- 喜剧：本文件 + 人物错误策略与升级
- 惊悚：本文件 + 风险升级
- 慢燃：本文件 + 微变化与人物弧

本文件不能把所有类型统一成同一种节奏。

---

# 十七、最终原则

```text
短剧不是更短的电影，
也不是切碎的电视剧。

它需要：
更快建立当前问题，
更高的有效变化密度，
更经济的人物证明，
更集中的场景功能，
更明确的单集职责，
更强的集间承接。

但所有速度，都必须建立在人物、因果和类型承诺成立的基础上。
```
