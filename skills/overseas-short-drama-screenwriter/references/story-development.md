# Story Development Reference

Use this file after a concept is selected and before full screenplay drafting.

## 1. Story foundation

Lock these first:

```yaml
foundation:
  logline:
  dramatic_question:
  theme_question:
  protagonist_external_goal:
  protagonist_internal_need:
  central_opposing_force:
  stakes:
  primary_emotional_promise:
  ending_state:
```

A story should be explainable as a causal chain, not a list of events.

```text
BECAUSE A HAPPENS,
THE PROTAGONIST CHOOSES B,
WHICH CAUSES C,
BUT C CREATES D,
SO THE PROTAGONIST MUST CHOOSE E.
```

Avoid:

```text
A happens,
then B happens,
then C happens.
```

## 2. Character construction

A major character needs dramatic usefulness, not merely biography.

For each lead define:

```yaml
character:
  name:
  age:
  social_identity:
  profession:
  external_goal:
  internal_need:
  fear:
  wound:
  flaw:
  strength:
  secret:
  contradiction:
  leverage:
  false_belief:
  truth_to_learn:
  opening_state:
  breaking_point:
  final_choice:
  ending_state:
```

### Want vs Need

`Want` drives visible plot behavior.

`Need` drives the internal arc.

They may align, but stronger character arcs often involve tension between them.

## 3. Protagonist agency test

For every 3–5 episodes, ask:

- What did the protagonist choose?
- What did that choice cost?
- What new situation did the choice create?

If the answer is repeatedly “someone else acted on them,” restore agency.

## 4. Antagonistic force

The antagonist / opposing force must have:

```yaml
opposition:
  goal:
  reason:
  resources:
  moral_logic:
  advantage_over_protagonist:
  vulnerability:
  escalation_strategy:
```

Do not rely on a villain who behaves irrationally only to extend episode count.

## 5. Relationship engine

For central pairings define:

```yaml
relationship:
  visible_bond:
  hidden_truth:
  attraction_or_dependency:
  conflict_of_interest:
  unequal_information:
  unequal_power:
  shared_history:
  mutual_need:
  mutual_fear:
  trust_level_start:
  major_break:
  major_repair_or_final_break:
  final_state:
```

A relationship should move through distinct states.

Example state progression:

```text
strangers
→ reluctant alliance
→ attraction
→ trust
→ betrayal
→ separation
→ truth
→ chosen partnership
```

Do not loop endlessly between “fight” and “make up” without new meaning.

## 6. Series engine test

A serial needs repeatable story pressure.

Test the engine with:

1. What problem remains after the first reveal?
2. What happens if the romantic misunderstanding is solved early?
3. Is there an external objective beyond the relationship?
4. Is there a secret with multiple layers rather than one binary reveal?
5. Can the antagonist alter strategy?
6. Can the protagonist win small battles while still losing ground overall?

If the entire series collapses after one honest conversation, strengthen the external engine.

## 7. Macro structure

Use phases based on story function.

### Phase A — Disruption

- establish protagonist under pressure
- reveal immediate want
- trigger irreversible change
- create a new story question

### Phase B — Entrapment / Commitment

- protagonist cannot easily return to old life
- central relationship or conflict becomes unavoidable
- first tactics fail or create new costs

### Phase C — Escalation

- opposing force adapts
- relationships deepen or fracture
- secrets generate consequences
- protagonist wins and loses in meaningful alternation

### Phase D — Major Reversal

- hidden information changes the meaning of earlier events
- power balance shifts
- protagonist changes objective or method

### Phase E — Major Loss

- protagonist pays the cost of previous choices
- central relationship reaches a breaking point
- old strategy becomes impossible

### Phase F — Counterattack

- protagonist acts with new understanding
- setups begin to pay off
- allies, enemies, or identities realign

### Phase G — Convergence

- external goal, relationship, secret, and antagonist pressures collide

### Phase H — Final Choice / Climax

- protagonist makes the hardest decision
- climax comes from accumulated choices and established capabilities

### Phase I — Payoff

- answer the dramatic question
- resolve the central emotional promise
- show the transformed state

## 8. Episode map

Every episode needs a state change.

Use:

```yaml
episode:
  number:
  opening_state:
  goal:
  obstacle:
  action:
  turn:
  new_information:
  emotional_payoff:
  relationship_shift:
  cliffhanger:
  ending_state:
```

The ending state must differ materially from the opening state.

## 9. Cliffhanger types

Use variety:

- danger already in motion
- identity contradiction
- relationship rupture
- impossible choice
- new evidence
- revealed betrayal
- power reversal
- unexpected arrival
- legal / financial consequence
- truth about a past event
- supernatural rule violation
- false victory collapsing

A cliffhanger should create a specific next question.

Bad:

> Everything was about to change.

Better:

> The DNA report shows the child cannot be Daniel's — but Daniel has already announced the engagement publicly.

## 10. Setup and payoff ledger

Track:

```yaml
setup:
  id:
  planted_episode:
  visible_to_audience:
  known_by_characters:
  intended_payoff:
  payoff_episode:
  status:
```

Status values:

```text
PLANTED
DEVELOPING
PARTIALLY_PAID
PAID_OFF
ABANDONED_WITH_REASON
```

Avoid forgotten major setups.

## 11. Reveal ladder

For important secrets, avoid a single on/off reveal when a layered reveal is possible.

Example:

```text
Level 1: something is wrong
Level 2: suspect identity is false
Level 3: evidence points to family member
Level 4: apparent culprit was protecting someone
Level 5: protagonist's own past caused the original event
```

Each reveal should change interpretation or strategy.

## 12. Emotional rhythm

Do not keep the audience at maximum intensity continuously.

Use contrast:

```text
pressure
→ breath
→ intimacy
→ threat
→ victory
→ consequence
```

Quiet scenes must still contain dramatic purpose.

## 13. Ending design

The ending should pay off three levels:

### Plot

Did the protagonist achieve or redefine the external goal?

### Relationship

What is the final state of the central bond?

### Character

What choice proves the protagonist changed — or failed to change?

Avoid endings solved by an unplanted coincidence or a new character appearing with the answer.
