# 创作模式路由

本文件负责决定当前短剧项目应该采用哪一种叙事模式。

主 Skill 是通用的“海外完整短剧编剧系统”，不默认把所有项目写成爽剧，也不默认把所有项目写成慢热剧。

核心原则：

> 先判断用户目标、目标国家、目标平台、受众和当前市场，再决定叙事模式。

如果用户已经明确“我要爽剧 / 悬疑 / 情感 / 喜剧 / 慢燃”等，不要擅自改类型。

如果用户没有明确模式，但要求“根据最新市场做项目”，先完成实时市场研究，再给出 2–4 个适合的模式方向供选择；如果无需用户选择也能明确判断，可标记为“暂定模式”继续推进。

---

# 一、通用底线

不论哪一种模式，都必须满足：

- 人物行为有因果
- 场景产生变化
- 每集承担明确职责
- 冲突不能只靠误会或巧合维持
- 人物不能为了拖集数故意变笨
- 信息、关系、目标、资源或风险必须持续发生变化
- 结尾悬念来自前面事件的后果，而不是任意切断
- 类型承诺必须持续兑现

“慢”不等于“拖”。

允许：

- 情绪发酵
- 克制表达
- 延迟揭秘
- 人物观察
- 关系细微变化
- 留白

但这些内容必须产生至少一种有效变化：

```text
认知变化
关系变化
风险变化
目标变化
信息变化
价值判断变化
人物选择变化
```

如果什么都没有变化，只是在等待，属于拖。

---

# 二、模式一：高爽商业模式

适用：

- 逆袭
- 复仇
- 身份翻转
- 豪门权斗
- 强女主 / 强男主
- 狼人、黑帮、超能力等高回报类型
- 用户明确要求“爽剧、爽文、快节奏、不拖”

必须读取：

`references/satisfaction-engine.md`

核心：

```text
快立痛点
→ 主角快速行动
→ 高频小兑现
→ 对手有效反制
→ 主角升级
→ 阶段大兑现
```

重点检查：

- 爽点债务
- 兑现速度
- 主角主动性
- 爽法重复
- 阶段大爽
- 终极兑现

---

# 三、模式二：情感关系模式

适用：

- 家庭
- 婚姻
- 亲情
- 治愈
- 成长
- 人际关系
- 情感现实题材

核心不是“每集打脸”，而是：

```text
关系压力
→ 选择
→ 误解 / 发现
→ 关系位置变化
→ 情绪代价
→ 更深层选择
```

重点检查：

- 人物真正想从对方那里得到什么
- 说出口与没说出口的差异
- 每集关系是否发生变化
- 情绪爆发是否有充分累积
- 和解、分离、原谅、放弃是否由人物行动换来

禁止：

- 用无限误会替代真实关系冲突
- 所有人只会哭和解释
- 情感爆发没有前置积累

---

# 四、模式三：悬疑 / 谜团模式

适用：

- 犯罪
- 秘密
- 身份谜团
- 调查
- 阴谋
- 心理悬疑

核心：

```text
问题建立
→ 线索
→ 假设
→ 行动
→ 新证据
→ 旧认知被推翻
→ 更深问题
```

重点维护：

- 观众知道什么
- 主角知道什么
- 对手知道什么
- 哪条线索是真的
- 哪条是误导
- 什么时候可以合理推理出来

悬疑允许延迟答案，但不能延迟推进。

每集至少需要推进：

- 新线索
- 新嫌疑
- 新风险
- 新解释
- 新反证

中的至少一项。

---

# 五、模式四：爱情 / 浪漫模式

适用：

- 浪漫喜剧
- 契约关系
- 第二次机会
- 禁忌爱情
- 敌对变恋人
- 久别重逢

核心发动机：

```text
吸引
+
阻碍
+
关系选择
+
代价
```

重点检查：

- 两个人为什么会被彼此吸引
- 为什么不能立刻在一起
- 每次关系推进后出现什么新问题
- 爱情是否改变人物的选择
- 两个人是否都具有主动性

禁止靠同一个误会无限拉扯。

---

# 六、模式五：喜剧模式

适用：

- 职场喜剧
- 浪漫喜剧
- 家庭喜剧
- 荒诞
- 黑色幽默

核心：

```text
人物欲望
→ 错误策略
→ 后果升级
→ 更糟选择
→ 喜剧性翻转
```

重点：

- 喜剧来自人物和处境，不只来自段子
- 笑点必须推动剧情或人物关系
- 同一包袱不能机械重复
- 人物认真对待自己的处境，观众才觉得好笑

---

# 七、模式六：黑暗 / 惊悚模式

适用：

- 生存
- 惊悚
- 黑暗关系
- 犯罪压迫
- 心理危险

核心：

```text
威胁建立
→ 安全感下降
→ 角色采取措施
→ 措施产生意外后果
→ 风险升级
```

重点：

- 风险必须具体
- 对手或威胁必须具有逻辑
- 主角不能靠反复做明显愚蠢的事制造危险
- 紧张必须来自信息差、时间、空间、选择和代价

---

# 八、模式七：慢燃 / 文艺 / 人物驱动模式

适用：

- 人物观察
- 现实主义
- 克制情感
- 生活流
- 反高潮
- 文艺类型

本模式允许：

- 更少事件
- 更长情绪积累
- 更细关系变化
- 更低频的大转折

但不允许“什么都不发生”。

每一场仍然必须改变：

```text
人物理解
关系距离
自我认知
价值判断
选择可能性
```

至少一项。

慢燃的判断标准：

> 事件可以慢，人物内部与关系状态不能静止。

---

# 九、模式八：混合类型

允许组合，例如：

```text
高爽 + 爱情
悬疑 + 情感
喜剧 + 爱情
复仇 + 悬疑
黑暗 + 浪漫
慢燃 + 悬疑
```

混合时必须明确：

```yaml
类型模式:
  主模式:
  次模式:
  主观众承诺:
  次观众承诺:
```

主模式控制全剧节奏与主要回报。

次模式提供差异化，不得反客为主导致类型承诺漂移。

---

# 十、模式选择记录

项目建立时记录：

```yaml
创作模式:
  主模式:
  次模式:
  节奏速度: 快 / 中快 / 中 / 慢燃
  主要观众回报:
  允许延迟的内容:
  必须快速兑现的内容:
```

模式不是永久不可改变。

如果市场研究或故事开发证明原模式不合适，可以提出切换，但必须记录：

- 原模式
- 新模式
- 修改原因
- 会影响哪些人物、分集和结局

然后更新项目状态。
