# 剧本医生：整剧诊断与重写

本文件用于所有创作模式的终稿前诊断，也可用于用户提供已有剧本后的问题定位与重写。

方法参考并重新整理自多套公开编剧资料，其中包括 @山音 的《山音超级编剧大师》公开项目，以及此前已吸收的剧本修订、场景诊断和编剧室方法。这里只吸收通用方法，不复制原始文本或完整模板。

核心原则：

> 先找根问题，再改表面症状。

不要一看到“台词不好”就先润色台词。很多台词问题其实来自场景没目标、人物没动机、结构没压力。

---

# 一、剧本医生工作顺序

默认顺序：

```text
类型承诺
→ 故事前提
→ 主角主动性
→ 人物弧
→ 连载发动机
→ 全剧结构
→ 多线交织
→ 分集功能
→ 场景权力变化
→ 对白与潜台词
→ 视觉化
→ 连续性
→ 本地化
→ 原创性
```

任何一层发现根问题，优先在该层修复，不用下游润色掩盖。

---

# 二、第一步：先写出一个“根问题”

正式诊断前，先尝试用一句话回答：

```text
这版剧本最大的问题是什么？
```

示例：

- 主角没有真正主动目标，导致后半段一直被事件推着走
- 核心关系没有利益冲突，解决误会后整部剧立刻失压
- 悬疑线索都在结尾才补，前面没有公平推理基础
- 喜剧主要靠段子，不靠人物错误策略制造升级
- 爽剧一直建立痛点，却没有对应兑现
- 情感剧的关系状态连续十集几乎不变

如果无法指出根问题，只能说明还没有真正读懂剧本。

---

# 三、类型承诺诊断

先读取：

`references/creative-modes.md`

检查：

```text
这是什么类型？
观众为什么点开？
观众为什么继续？
这部剧承诺的核心回报是什么？
当前稿件有没有持续兑现？
```

高爽看回报与掌控感。

悬疑看问题链、线索与揭秘满足。

爱情看吸引、阻碍、选择和关系推进。

情感看关系、认知和情绪代价。

喜剧看人物错误策略与后果升级。

惊悚看风险、威胁和生存选择。

慢燃看人物与关系的细微但真实变化。

如果类型承诺漂移，先修类型，不要先修台词。

---

# 四、人物诊断

读取：

`references/character-visual-dramaturgy.md`

逐个主要人物检查：

```text
他想要什么？
为什么现在必须得到？
什么错误信念影响他的选择？
他主动做了什么？
他的选择造成了什么后果？
他在不同压力下有没有换策略？
高潮时做出的选择和开篇有什么本质区别？
```

常见问题：

- 只有背景，没有目标
- 只有性格标签，没有行为证据
- 只被事件推动
- 关键胜利由别人完成
- 人物弧靠台词宣布
- 前后选择没有变化
- 为了剧情方便突然变聪明或变笨

---

# 五、连载发动机诊断

读取：

`references/series-engine-character.md`

检查：

```text
如果把主要误会说开，故事还能继续吗？
如果秘密提前揭开，是否还有真实冲突？
后续事件是否来自前面人物选择的后果？
对手会不会学习和换招？
观众期待的核心情绪是否可以持续产生但不重复？
```

如果故事只能靠：

- 新反派
- 新误会
- 新巧合
- 新秘密

不断续命，说明发动机不健康。

---

# 六、全剧结构诊断

不按固定页码判断。

检查：

```text
开篇是否尽快建立核心问题？
第一次重大选择是否真正改变局势？
中段是否改变规则、目标、意义或权力？
重大损失是否来自前面选择，而不是作者硬塞？
后半段是否只是前半段冲突升级版的重复？
高潮是否逼主角做最终选择？
结局是否同时回应外部问题、关系问题和人物变化？
```

结构模板只是诊断工具，不是填空题。

---

# 七、多线交织诊断

适用于存在两条以上主要故事线的项目。

先列：

```yaml
故事线:
  A线:
  B线:
  C线:
```

逐条检查：

```text
A线的选择有没有改变B线？
B线的信息有没有改变A线？
关系线是否影响外部主线？
秘密线是否改变人物关系？
支线是否只在主线停下时才出现？
某条线删掉后主线是否几乎完全不受影响？
```

如果支线长期没有因果作用，优先合并、删除或重新连接。

---

# 八、分集诊断

对每集回答：

```text
本集职责是什么？
本集谁最想得到什么？
本集发生了什么不可忽略的变化？
删除这一集会损伤什么？
本集结尾为什么自然产生下一集？
```

危险信号：

- 删除后主线完全不受影响
- 只是解释前情
- 只是重复上一集情绪
- 只是等待下一件事
- 集尾靠突然切断制造假悬念

不同类型额外按模式检查。

---

# 九、场景诊断

每场检查：

```text
谁想得到什么？
谁阻止？
人物用了什么策略？
对方怎么反制？
场景前谁占优势？
场景后谁占优势？
有什么信息、关系、风险或认知发生变化？
这场造成了什么不可逆后果？
```

如果一场只有谈话，没有策略变化和状态变化，优先重写。

如果同一个信息能在更有冲突的场景里完成，合并。

---

# 十、对白诊断

读取：

`references/dialogue-scene-diagnostics.md`

先问：

> 这是对白问题，还是场景问题？

对白逐句检查：

```text
这句话想让对方做什么？
能不能更短？
是否重复画面？
是否重复上一句？
双方是不是在告诉彼此都知道的背景？
真正意思是否全部说出来了？
角色声音能否区分？
```

不要把所有人物都写成聪明、完整、漂亮地表达自己。

---

# 十一、视觉化诊断

读取：

`references/character-visual-dramaturgy.md`

扫描以下句式：

```text
意识到
觉得
感到
明白
心里
内心
想起
非常愤怒
非常难过
```

不是一律删除，而是判断：

> 这个信息能不能通过行为、选择、关系、物件、空间或对白策略表现？

重要场景做“静音测试”：

> 如果关掉声音，是否仍能看出人物关系、谁占优势、发生了什么变化？

如果完全看不出来，说明场景可能过度依赖口头解释。

---

# 十二、节奏诊断

不要只用“快 / 慢”评价。

检查单位时间内是否发生：

- 目标变化
- 信息变化
- 关系变化
- 风险变化
- 权力变化
- 选择变化

快节奏但没有变化，是空。

慢节奏但变化真实，是成立的。

真正的问题是“停滞”。

---

# 十三、连续性诊断

读取项目状态和故事设定总表。

重点查：

- 人物知道 / 不知道 / 误以为
- 时间顺序
- 地点与移动
- 伤势与恢复
- 物品所有权
- 金钱与资源
- 关系状态
- 已公开秘密
- 已埋伏笔
- 已回收伏笔
- 世界规则
- 法律与制度限制

发现矛盾先判断：

```text
是作者忘了？
还是人物故意撒谎？
还是观众之前得到的是错误信息？
```

三者不能混为一谈。

---

# 十四、本地化诊断

读取：

`references/localization.md`

重点检查：

```text
故事是否只是中国逻辑换外国名字？
家庭权力是否符合当地现实？
职业和公司机制是否可信？
法律、医疗、教育、警务是否影响因果？
金钱、住房、婚恋、阶层符号是否自然？
人物解决冲突的方式是否符合当地社会行为？
```

影响剧情的现实事实必须查证。

---

# 十五、原创性诊断

如果项目来自市场研究、热门题材或参考样本，检查：

```text
人物组合是否过像？
触发事件是否过像？
秘密结构是否过像？
反转顺序是否过像？
标志性道具是否过像？
高潮机制是否过像？
结局是否过像？
```

学习的是类型需求、情绪机制和结构规律，不是具体故事。

---

# 十六、诊断报告格式

推荐输出：

```yaml
剧本医生报告:
  最大根问题:
  影响等级: 致命 / 高 / 中 / 低
  具体证据:
  为什么会伤害剧本:
  最小修复方案:
  会影响的集数或场次:
  修复后的连锁影响:
```

然后按优先级列出最多 5–10 个主要问题。

不要平均分配篇幅给所有小毛病。

---

# 十七、重写顺序

默认：

```text
1. 类型承诺
2. 故事前提与主角目标
3. 连载发动机
4. 人物弧与关系
5. 全剧结构
6. 多线交织
7. 分集职责
8. 场景权力与策略变化
9. 对白与潜台词
10. 视觉化
11. 连续性
12. 本地化与原创性
```

修改上游后，必须重新检查受影响的下游。

例如改了角色核心动机，就要重新检查：

- 分集选择
- 关系线
- 场景目标
- 高潮
- 对白

不能只改人物小传。

---

# 十八、剧本医生完成标准

```text
□ 能说出最大根问题
□ 诊断有具体剧本证据
□ 没有用“感觉不够好”代替分析
□ 修改建议能执行
□ 修改顺序从上游到下游
□ 类型承诺没有被修丢
□ 人物弧通过选择证明
□ 多线故事互相造成后果
□ 关键场景存在权力 / 信息 / 关系 / 风险变化
□ 对白不是主要用来解释剧情
□ 重要心理变化被尽量视觉化
□ 连续性和本地化没有被改坏
```

最终原则：

> 剧本医生不是把句子写得更漂亮，而是让故事重新获得因果、人物、压力、变化和观众回报。
