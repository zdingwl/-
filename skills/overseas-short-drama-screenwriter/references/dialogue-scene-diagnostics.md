# 场景与对白诊断规则

用于：完整场景已经写出之后，不是继续堆台词，而是判断这场戏为什么不够有力，并从结构、人物行动、信息和语言四层修复。

---

# 1. 先判断问题是不是对白问题

很多“对白不好”的真正原因是：

- 人物没有明确目标
- 双方目标并不冲突
- 场景没有代价
- 场景没有转折
- 人物只是负责解释背景
- 同一策略反复三遍

因此修对白前先问：

```text
谁想得到什么？
谁阻止？
为什么必须现在谈？
如果谈失败，谁会失去什么？
场景前后有什么变化？
```

这些都回答不清时，先修场景，不要润色句子。

---

# 2. 对白三层

每句重要对白至少考虑：

```text
表面说了什么
↓
人物故意没有说什么
↓
人物自己也不愿承认什么
```

例如：

表面：
> 今晚还回来吗？

未说：
> 你是不是又要去见她？

不愿承认：
> 我害怕你已经不需要这个家。

不要把后两层都直接写成台词。

---

# 3. 对白必须是行动

给重要台词标一个动作动词：

- 逼迫
- 诱导
- 试探
- 安抚
- 威胁
- 贬低
- 求饶
- 拖延
- 撒谎
- 讨价还价
- 转移
- 挑衅
- 争夺定义权
- 夺回控制权

如果连续几句的动作动词完全一样，说明节拍重复。

例如：

```text
乞求
→ 乞求
→ 乞求
```

应考虑改成：

```text
乞求
→ 威胁
→ 揭露秘密
```

策略变化才会让场景推进。

---

# 4. 解释型对白四级修法

遇到背景说明，不要第一反应“删掉”。

按顺序尝试：

## 一级：变成筹码

让人物为了当前目标使用这条信息。

## 二级：延迟

观众暂时不需要知道的，晚一点再揭露。

## 三级：拆散

把一大段背景分散到不同场景的行动中。

## 四级：视觉化

用物件、证据、行为、关系反应代替口头说明。

原则：

> 信息不是作者给观众上课，而是人物改变局势的武器。

---

# 5. 不要让人物互相告诉对方都知道的历史

危险句型：

```text
你还记得十年前爸爸去世后，我们搬到这里……
```

如果两个人都知道，就不自然。

可以改成冲突：

```text
你没资格说这是你的公司。

爸死后，是我把它救回来的。

你只是坐上了他的椅子。
```

观众获得背景，同时场景仍在争夺权力。

---

# 6. 过度直白诊断

以下情况容易“写在脸上”：

- 人物准确说出自己的心理问题
- 人物直接总结双方关系
- 人物把主题说成演讲
- 情侣直接说“我害怕再次被抛弃，所以我推开你”

修法：

```text
把情绪变成策略
把策略变成行为
让对方通过行为推断情绪
```

但不要机械追求所有台词都有隐喻。短剧需要清楚，关键是“人物是否在行动”，不是“越晦涩越高级”。

---

# 7. 沉默也属于对白设计

可以使用：

- 不回答
- 看向第三人
- 把文件收走
- 改口
- 删掉消息
- 放下戒指
- 把椅子移远
- 起身离开

这些都是对上一句台词的反应。

如果每一次情绪都通过一句完整台词表达，剧本会很像朗读稿。

---

# 8. 双人对话变僵时，引入“第三压力点”

不一定真的增加第三个人物。

可以让双方争夺：

- 一个孩子
- 一份合同
- 一段录音
- 一笔遗产
- 一个病人
- 一场公开活动
- 一件道具
- 一个共同秘密

于是对话从：

```text
你伤害我
我没有
你有
我没有
```

变成：

```text
双方都想控制一个第三对象的意义、归属或后果
```

冲突会更具体。

---

# 9. 角色声音指纹

主要角色至少区分：

```yaml
voice:
  sentence_length:
  vocabulary_level:
  directness:
  formality:
  humor:
  anger_style:
  deflection_style:
  lie_style:
  intimacy_style:
  profession_words:
  phrases_never_used:
```

遮住人物名字后，仍应有一定辨识度。

不要靠口头禅硬区分人物。

真正的差异来自：

- 句长
- 信息量
- 攻击方式
- 回避方式
- 是否直说
- 谁习惯问问题
- 谁习惯下结论
- 谁在压力下变得更短
- 谁在压力下反而说更多

---

# 10. 场景五步诊断

每场写完后检查：

```text
1. 谁驱动场景？
2. 对抗力量是什么？
3. 开场价值是什么？
4. 人物策略在哪里发生变化？
5. 结尾价值变成什么？
```

如果开头和结尾价值完全相同，优先怀疑这场只是解释。

---

# 11. 重复节拍是最常见的场景病

例：

```text
A求B留下
B拒绝
A换一句话继续求
B继续拒绝
A再换一句话继续求
B继续拒绝
```

字变了，行动没变。

修法：

- 改策略
- 加代价
- 加新信息
- 让权力翻转
- 让第三压力点介入
- 让其中一人改变目标

---

# 12. 场景晚进早出

进入得太早：

```text
进门
坐下
倒水
寒暄
铺背景
终于开始冲突
```

应尽量从：

> 对方已经拒绝签字。

开始。

结束得太晚：

```text
转折已经发生
人物又解释一遍
再总结一遍
再说“那我们就这样吧”
```

转折完成后尽快离开。

---

# 13. 场景地点也要做功

如果一个场景可以无损地发生在任何地方，考虑场景是否太抽象。

问：

```text
为什么必须在这里？
这个地点能不能增加人物压力？
地点里有什么东西能进入冲突？
```

例如同样是谈离婚：

- 私人客厅
- 孩子的学校活动
- 律师事务所
- 婚礼现场后台

会产生完全不同的限制和行为。

不要为了“有画面”随机换奇怪地点，地点必须改变人物可做什么、不能做什么。

---

# 14. 动作优于情绪标签

少写：

> 她非常愤怒、痛苦又失望。

优先找一个具体选择：

> 她把共同账户的银行卡剪断。

动作不只是“好看”，而是应该改变关系、资源或局势。

---

# 15. 场景压缩测试

每场最后问：

```text
能不能晚10秒进入？
能不能早10秒离开？
能不能删一句而意思更强？
能不能用动作代替一句解释？
有没有两个场景在完成同一功能？
```

---

# 16. 对白诊断清单

```text
□ 每句重要对白都有行动目的
□ 人物不会互相复述双方都知道的信息
□ 重要信息尽量作为筹码进入冲突
□ 连续节拍没有一直使用同一种策略
□ 有适量沉默、打断、回避、答非所问
□ 主要角色说话方式有差异
□ 没有人人都能准确描述自己的心理
□ 没有用漂亮台词掩盖场景没有冲突
□ 解释性长段已尽量压缩
□ 台词在场内人物之间有效，不只是给观众听
```

---

# 17. 场景诊断清单

```text
□ 场景有明确驱动人物
□ 有对抗力量
□ 有代价
□ 有策略变化
□ 有价值变化
□ 有具体地点意义
□ 删除本场会损伤剧情、人物或信息链
□ 没有重复上一场功能
□ 转折发生后及时离场
□ 下一场由本场后果自然产生
```

核心原则：

> 好对白来自人物在做事；好场景来自人物做事以后世界发生变化。
