# 回归测试案例库

用于测试不同类型和不同国家项目，避免 Skill 只会写一种模板。

测试时固定输入，分别让旧版与新版生成，再隐藏版本标签进行比较。

## 案例一：高爽商业

```text
目标国家：美国
类型：复仇 + 商业竞争 + 女性成长
集数：60集
单集时长：60–90秒
要求：高爽、快推进，但不能靠重复打脸和突然获得关键资源。
```

重点观察：主角是否主动、阶段兑现是否清楚、对手是否会调整策略、同一种爽法是否重复。

## 案例二：悬疑

```text
目标国家：英国
类型：心理悬疑
集数：40集
单集时长：60–90秒
要求：允许延迟答案，但每集必须推进调查、风险或认知。
```

重点观察：线索是否公平、知识状态是否一致、中段是否只靠拖延维持悬念。

## 案例三：爱情

```text
目标国家：美国
类型：第二次机会爱情
集数：50集
单集时长：60–90秒
要求：不靠同一个误会反复拉扯；两个人都要有主动性。
```

重点观察：吸引、阻碍、选择和关系变化是否由具体事件推动。

## 案例四：家庭情感

```text
目标国家：韩国
类型：家庭关系 + 成长
集数：36集
单集时长：90秒
要求：不需要高频打脸，但每集关系或认知必须变化。
```

重点观察：新版是否错误套用爽剧规则，情绪积累是否自然。

## 案例五：职场喜剧

```text
目标国家：加拿大
类型：职场喜剧
集数：30集
单集时长：60秒
要求：笑点来自人物和处境，不靠段子拼接。
```

重点观察：喜剧是否推动剧情和关系，而不是独立笑话合集。

## 案例六：高压生存类型

```text
目标国家：澳大利亚
类型：封闭空间高压剧情
集数：24集
单集时长：60–90秒
要求：风险升级来自人物选择、空间限制和信息差，不能靠角色反复做明显错误决定。
```

重点观察：紧张感是否来自因果和选择。

## 案例七：慢燃人物剧

```text
目标国家：日本
类型：现实主义人物关系
集数：24集
单集时长：90–120秒
要求：事件密度低，但人物认知和关系位置持续变化。
```

重点观察：Skill 是否能允许慢节奏而不误判为拖，同时保留留白、克制和细微变化。

## 案例八：长篇连续性压力测试

```text
目标国家：美国
类型：商业悬疑 + 家族关系
集数：80集
单集时长：60–90秒
要求：多条人物关系、多层秘密、关键证据和公司控制权持续变化。
```

重点观察：中段是否出现人物知识漂移、关系重置、物件状态矛盾、重复冲突和伏笔遗忘。

## 隐藏测试

至少保留 2 个不参与日常调规则的案例，只在大版本验收时使用。

隐藏案例应更换国家、类型组合、受众、节奏、集数和核心关系，用于检测 Skill 是否真正具有泛化能力。
