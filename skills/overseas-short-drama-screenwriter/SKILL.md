# 海外短剧完整剧本技能 2.8

## 一、核心定位

本技能是一套可按项目类型切换叙事模式的海外短剧完整编剧系统。

它不是单一爽剧模板，不是电影剧本压缩版，也不是传统电视剧拆碎版。

完整流程：

```text
确认目标国家
→ 本次实时市场研究（市场驱动项目）
→ 确定创作模式
→ 市场机会与原创创意池
→ 目标国家本地化
→ 故事前提 / 主题 / 核心戏剧问题
→ 人物 / 关系 / 人物弧光
→ 连载故事发动机
→ 追剧欲与观众观看驱动力【核心门槛】
→ 全剧宏观结构
→ 短剧媒介转换
→ 全集结构表
→ 前3集完整试播稿【核心门槛】
→ 通过后再继续批量逐集写作
→ 伏笔 / 揭秘 / 回收
→ 场景任务卡 / 权力变化
→ 逐集完整中文短剧剧本
→ 项目状态 / 故事设定总表 / 连续性更新
→ 场景与对白诊断
→ 长篇一致性扫描
→ 剧本医生整剧诊断
→ 独立冷读质检
→ 修订
→ 最终中文完整剧本
```

用户要求“完整剧本”时，最终必须写到：

```text
集数
+
场次
+
动作
+
人物行为
+
完整对白
+
每集结尾
```

不能只交创意、梗概或分集简介。

# 二、最高优先级硬规则

## 1. 目标国家必须先确认

创建海外项目之前必须知道主目标国家。

如果用户只说“海外、欧美、英文市场、欧洲、拉美”等，而任务需要本地化，先确认主目标国家。

禁止默认美国。

主目标国家控制：

- 当前市场研究
- 社会制度
- 职业与公司逻辑
- 家庭与婚恋
- 阶层符号
- 货币
- 法律、医疗、学校、警务
- 人物行为与表达逻辑

---

## 2. 最新市场必须本次实时检索

只要任务涉及：

```text
最新 / 当前 / 近期 / 热门 / 爆款
榜单 / 排名 / 趋势 / 增长
下载 / 收入 / 市场份额
现在流行什么 / 根据国外市场创作
```

必须在本次任务中实际进行外部实时检索。

模型训练知识与历史记忆只能用于编剧理论、通用概念和明确标注的历史背景。

禁止用于证明当前榜单、当前爆款、当前平台热度和当前受众偏好。

读取：

`references/market-research.md`

---

## 3. 用户可见内容默认全部中文

默认：

```yaml
剧本输出语言: 简体中文
对白输出语言: 简体中文
```

包括市场分析、创意、人物、分集、场景、动作、对白、诊断和终稿。

海外本地化是“故事逻辑符合目标国家”，不等于必须输出外语。

只有用户明确要求英文版、其他外语版或中外文对照时，才生成外语。

---

## 4. 学习市场，不复制作品

允许学习：

- 题材
- 情绪承诺
- 人物原型
- 关系模式
- 冲突机制
- 钩子类型
- 观看驱动力
- 连载发动机
- 节奏规律

禁止复制：

- 人物姓名
- 独特人物组合
- 标志性场景
- 台词
- 独特道具
- 完整剧情节点顺序
- 特有反转
- 高潮机制
- 结局
- 标题

市场研究和爆文拆解的目标是提取机制，不是换皮。

# 五、故事与人物

读取：

`references/story-development.md`

`references/character-visual-dramaturgy.md`

正式写正文前至少锁定：

```text
故事前提
主题问题
核心戏剧问题
主角外在目标
主角内在需求
主角错误信念
核心关系
主要对抗力量
失败代价
人物弧证明方式
完整故事线
最终结局
```

核心因果：

```text
因为 → 所以 → 但是 → 因此
```

人物弧必须通过高代价选择证明，不用台词宣布“我成长了”。

重要心理变化优先转成动作、选择、停顿、物件处理和关系行为。

# 六、连载发动机

读取：

`references/series-engine-character.md`

进入全集结构前完成：

- 三集自然延展测试
- 人物关系网
- 主角压力阶梯
- 对手策略升级
- 信息不对称设计
- 故事自然失压点判断

特别检查：

```text
如果一个误会现在说开，故事是不是马上结束？
如果一个秘密现在揭开，后面还有没有真实冲突？
后续集是否来自前集选择的后果？
对手是否会根据主角行动调整策略？
```

发动机弱时先修发动机，不靠随机新增反派和误会拖集数。

# 七、追剧欲与观众观看驱动力【所有类型核心门槛】

进入大量分集和完整正文前必须读取：

`references/narrative-momentum.md`

核心不是“有没有钩子”，而是：

> 观众为什么现在还不退出？为什么这一集结束后仍然想点下一集？

必须同时管理三层：

```text
情绪站队
+
观众问题链
+
阶段期待 / 终局期待
```

每个阶段必须能回答：

```text
观众现在站谁？
观众现在最想知道什么？
观众现在最期待什么发生？
```

如果三者都弱，不能靠随便加反转或悬崖结尾补救，必须回到人物、关系、秘密、冲突或终局期待重构。

### 7.1 情绪站队

尤其高爽、情感、爱情、家庭、职场、复仇项目要明确：

```yaml
情绪站队:
  观众当前支持谁:
  最反感谁或什么行为:
  最希望谁后悔:
  最希望主角夺回什么:
```

### 7.2 观众问题链

每集维护：

```yaml
观众问题链:
  开集最大问题:
  当前最期待事件:
  当前最担心后果:
  本集确认:
  本集推翻:
  本集部分回答:
  故意延迟的问题:
  延迟时提供的新价值:
  集尾最大问题:
  下一集必须提供的新价值:
```

延迟答案时必须给新信息、选择、关系变化、风险升级、阶段回报或更具体的问题。

### 7.3 未知悬念与预期型悬念

同时管理：

```text
观众不知道答案，所以想知道。
```

和：

```text
观众已经知道答案，但在等某个人什么时候知道、知道后会怎样。
```

关键秘密记录：

```yaml
信息差:
  观众知道:
  主角知道:
  对手知道:
  谁还不知道:
  观众正在等待谁知道:
  一旦知道会改变什么:
```

### 7.4 终局期待

不是只写“最终结局”，还要明确观众真正等着看的未来画面：

```yaml
终局期待:
  最想看到的最终画面:
  最想看到谁后悔或改变:
  最想看到什么真相公开:
  最想看到哪段关系作出最终选择:
  最想看到主角夺回 / 放下 / 完成什么:
```

### 7.5 可预测性

目标不是“什么都猜不到”。

原则：

```text
大方向可以期待
+
具体兑现方式不能过于显然
```

优先通过人物选择、代价、信息意义、关系后果、对手适应和成功副作用制造变化，不靠随机反转。

### 7.6 小兑现必须制造新后果

优先：

```text
兑现旧承诺
→ 改变局势
→ 产生新代价或更高层问题
→ 启动下一轮故事
```

不能“打一巴掌爽完，下一集世界归零重新受欺负”。

# 八、短剧媒介转换【所有类型必读】

读取：

`references/short-drama-medium.md`

核心判断：

> 短剧不是更短的电影，也不是切碎的电视剧。

统一要求：

- 尽快建立当前问题
- 尽量从人物主观处境进入，而不是先讲世界观
- 单集形成微型戏剧单元
- 单位时间保持较高有效变化密度
- 场景短而完整，不短而碎
- 信息进入冲突，不脱离剧情讲解
- 人物快速可识别，但仍有长期弧光
- 集尾来自本集后果，不靠机械切断
- 台词强调行动密度，不机械限制字数
- 慢燃允许低事件密度，但不允许零变化
- 不用固定秒数、固定反转次数替代戏剧判断

短剧“有效变化”包括：

```text
目标
关系
权力
风险
信息
认知
选择
资源
秘密状态
观众预期
类型回报
```

# 九、全剧结构与全集结构

结构可以使用三幕、四幕、五幕、十五节拍、英雄旅程、七点结构或自定义阶段，但不能为了模板增加无因果事件。

正确顺序：

```text
完整故事
→ 全剧阶段结构
→ 追剧欲设计
→ 短剧媒介转换
→ 全集结构表
→ 关键转折 / 伏笔 / 揭秘 / 回收
→ 前3集完整样稿
→ 试播门槛
→ 通过后继续完整正文
```

禁止一句创意直接自由生成几十集完整正文。

---

# 十、前3集试播门槛【强制】

长剧进入大规模完整正文前，优先完成前3集完整剧本。

检查：

```text
看完第1集，观众是否已经进入一个明确人物处境？
看完第1集，观众是否站队或形成情感投入？
看完第1集，是否存在明确进入第2集的理由？
看完第2集，是否获得新价值，而不是继续拖第1集的问题？
看完第3集，是否证明存在持续的连载发动机？
是否至少有两个观看驱动力在工作？
是否已经形成阶段期待或终局期待？
完全不知道后续大纲时，只看3集是否仍然自然想看第4集？
```

如果结论只是：

```text
逻辑完整
人物清楚
铺垫充分
```

但没有明确“还想继续”，视为不通过。

不通过时优先返回修改：

- 开局异常变量
- 主角欲望
- 情绪站队
- 核心关系
- 第一阶段秘密
- 信息差
- 选择代价
- 第一轮重要回报
- 阶段期待 / 终局期待

禁止明知前3集没吸引力仍继续批量生成几十集。

# 十三、类型专项模块

## 高爽商业

用户明确要爽剧、爽文改编、复仇、逆袭、身份翻转或高频回报时读取：

`references/satisfaction-engine.md`

重点：

- 情绪债务
- 爽点债务
- 主角主动性
- 兑现速度
- 爽法重复
- 阶段大兑现
- 终极兑现

这些不是所有短剧的通用硬规则。

## 非爽剧

不强制“每集都要小爽”。

但必须持续发生至少一种真实变化：

```text
关系
认知
风险
目标
信息
人物选择
价值判断
```

悬疑可以延迟答案，但不能延迟推进。

情感可以慢热，但关系不能长期静止。

慢燃可以少事件，但人物认知与关系位置不能长期静止。

喜剧可以松弛，但笑点必须来自人物和处境，并推动人物或剧情。

# 十五、小说与素材短剧化

读取：

`references/adaptation.md`

并强制经过：

`references/narrative-momentum.md`

`references/short-drama-medium.md`

正确顺序：

```text
找核心冲突
→ 找核心观众承诺
→ 找主角主动性
→ 找观众问题与终局期待
→ 提取关键因果链和可见行动
→ 压缩人物和支线
→ 重排信息与秘密
→ 重新设计情绪站队与信息差

```

禁止机械使用：

```text
小说第1章 = 短剧第1集
电影前3分钟 = 短剧第1集
电视剧一场戏 = 短剧一集
```

# 十六、场景、对白与追剧欲诊断

场景对白读取：

`references/dialogue-scene-diagnostics.md`

观看驱动力读取：

`references/narrative-momentum.md`

重点检查：

```text
人物是否在主动争取东西？
场景前后是否有状态移动？
对白是否只是解释？
观众现在到底站谁？
观众现在最想知道什么？
观众现在最期待什么发生？
这一集给了什么新价值？
小兑现是否产生新后果？
秘密是在推进还是只被拖延？
下一集如果按最显然路线发展是否太好猜？
集尾是否来自本集后果？
```

如果没有继续观看理由，不能仅靠加一句神秘台词或突然切黑修复。

# 十七、剧本医生与独立质检

- 为了潜台词而不说人话
- 为了视觉化而堆无意义动作
- 为了快节奏破坏人物、因果和情绪

# 二十一、完整剧本完成标准

任何完整短剧剧本都必须满足：

```text
□ 目标国家明确
□ 市场驱动项目使用本次实时资料
□ 创作模式明确，没有无意识类型漂移
□ 故事原创，不是热门作品换皮
□ 类型承诺持续兑现
□ 人物有外在目标、内在需求和可验证的人物弧
□ 人物行为符合目标、知识和压力
□ 主角的选择持续制造后果
□ 对手或阻碍力量会根据主角行动变化
□ 连载发动机能够持续产生新冲突
□ 情绪站队、观众问题链和阶段/终局期待至少形成有效观看驱动力
□ 重要秘密区分观众知道与人物知道，并合理使用未知型和预期型悬念
□ 已做可预测性检查：大方向有期待，具体兑现不过分显然
□ 小兑现会改变局势并制造下一步后果
□ 已经过短剧媒介转换，而不是电影 / 电视剧直接压缩或切碎
□ 前3集试播门槛通过，具备自然继续观看动力
□ 每集承担明确职责
□ 每集至少存在一种有效状态变化
□ 每集能够回答“观众现在最想知道什么、最期待什么发生”
□ 开场能够尽快进入人物具体处境
□ 场景短而完整，不是无因果碎片
□ 信息进入冲突，不依赖长篇讲解
□ 关键场景存在权力、关系、信息或风险移动
□ 重要心理变化尽量通过行为和选择表现
□ 对白有行动、潜台词和人物差异
□ 不使用固定秒数、固定反转次数替代戏剧判断
□ 集尾主要来自本集行为后果，不依赖机械切黑
□ 没有靠人物降智、无限误会和随机巧合拖集
□ 长剧人物事实、时间、知识、关系、物件和规则保持连续
□ 长剧中段已进行加密连续性检查
□ 本地化符合目标国家现实
□ 默认向用户交付中文完整剧本
□ 已经过剧本医生整剧诊断
□ 重要项目完成独立质检或明确标记质检级别
□ 已经过追剧欲、结构、人物、短剧媒介、场景、对白和连续性修订
□ 没有混入下游分镜和视频生成内容
```

模式专项附加标准：

- 高爽：检查情绪债务、爽点债务、兑现速度、主角主动性和爽法重复
- 悬疑：检查线索公平、知识状态、误导合理性和揭秘链
- 情感 / 爱情：检查关系变化、选择代价和情绪积累
- 喜剧：检查笑点是否来自人物与处境并推动剧情
- 高压 / 惊悚：检查威胁逻辑、风险升级和角色应对
- 慢燃 / 文艺：检查人物认知、关系和未完成情绪是否持续变化

最终原则：

```text
短剧不是更短的电影，
也不是切碎的电视剧。

好剧本不只要“写得对”，
还要让观众心里一直有一件没放下的事。

观众要不断得到东西，
同时不断产生新的期待。

慢可以，但不能拖；
快可以，但不能空。
```
