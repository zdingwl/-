# v2.0.0 Release Notes

## Novel To Screenplay Studio 2.0

这一版本把最初的“小说到剧本 foundation”升级为完整编剧工作系统。

### 两种入口

1. 小说 / IP / 已有素材 → 剧本
2. 原创概念 → 完整剧本

### 四种媒介

- 电影
- 电视剧 / 流媒体剧集
- 短剧 / 微短剧
- 动画

### 主要升级

**改编不再等于缩写。**

系统现在会：

- 建立 Source Index
- 找 Story DNA
- 进行 KEEP / TRANSFORM / MERGE / MOVE / CUT / INVENT 决策
- 把内心戏转换成可见选择和行动
- 合并角色与支线
- 重排 POV、时间线和 Reveal
- 为目标媒介重建结构

**原创不再停在创意。**

系统会从：

`Concept → Premise → Character → Story Spine → Beat → Scene → Full Script`

持续推进到完整剧本。

**长篇不再只靠“记忆”。**

新增：

- Story Bible
- Knowledge State
- Secret Ledger
- Object / Resource State
- Setup / Payoff Ledger
- Handoff State

**修订不再先修漂亮台词。**

Script Doctor 按：

`Premise → 主角 → 因果 → 人物 → 结构 → 场景 → 信息 → 对白 → 连续性`

逐层找根问题。
