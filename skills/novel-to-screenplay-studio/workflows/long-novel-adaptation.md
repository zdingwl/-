# Workflow：长篇 / 百万字小说 → 剧本

适用：多卷、数十万至百万字小说、系列网文、多文件 IP。

---

# Phase 0：初始化

创建：

- Project State
- Source Index
- Story Bible
- Adaptation Bible
- Timeline
- Secret Ledger
- Setup / Payoff Ledger
- Knowledge State

此时 Story Bible 允许为空壳，不提前猜结论。

---

# Phase 1：扫描全部素材

先确定：

```text
文件 → 卷 → 章 → 顺序 → 大致规模
```

如果是多文件，先建立全目录清单。

不要立刻开始写剧本。

---

# Phase 2：第一遍功能读取

按可管理 Chunk 读取。

每个章节提取：

```text
POV
剧中时间
人物
事件
选择
后果
关系变化
信息
秘密
Setup / Payoff
情绪价值
```

更新 Source Index。

---

# Phase 3：全局合并

每完成一个卷或合理批次：

- 去重人物
- 合并别名
- 更新时间线
- 合并秘密
- 建立人物互动网络
- 追踪物件
- 标记未解释冲突
- 标记后文可能重解释的事实

任何未经后文验证的结论标记 ASSUMED。

---

# Phase 4：第二遍关键深读

深读：

- 开篇异常
- 触发事件
- 核心关系第一次变化
- 重大选择
- 中段
- 最大 Reveal
- 低谷
- 高潮
- 结局
- 人物弧证明
- 重要 Setup 的首次出现

此阶段目标是回答“原作为什么成立”。

---

# Phase 5：Story DNA 收敛

锁定：

- 主角
- 外在目标
- 内在需求
- Misbelief
- 核心戏剧问题
- 主题问题
- 核心关系
- 对抗
- Stakes
- 情绪承诺
- Ending State

没有读到结局前，不锁 Ending State。

---

# Phase 6：改编风险报告

执行：

- 适配度评分
- 压缩压力
- 多 POV 风险
- 人物合并风险
- 时间线风险
- Reveal 风险
- 制作规模风险

生成 Adaptation Risk Report。

---

# Phase 7：Chapter Function Map

为原作章节标记功能。

然后按功能聚类：

```text
同一因果链
同一人物阶段
同一秘密推进
同一关系阶段
同一重大目标
```

这些聚类是“影视 Sequence 候选”，不是直接集数。

---

# Phase 8：章 → 影视 Sequence

映射原则：

```text
原章节
→ 抽取戏剧功能
→ 删除重复
→ 合并同功能
→ 重排 Reveal
→ 找不可逆变化
→ 组成 Sequence
```

一个 Sequence 至少要有：

- 当前目标
- 升级
- 转折
- 离开状态

---

# Phase 9：Sequence → Episode / Act

## 剧集

按以下边界优先切集：

- 新目标产生
- 关系状态不可逆变化
- Reveal 改变策略
- 阶段性胜负
- 风险层级改变

## 短剧

再把 Sequence 拆成高密度微单元。

## 电影

把 Sequence 压成段落，不制造虚假 Episode。

---

# Phase 10：Adaptation Matrix

逐个重要元素决定：

KEEP / TRANSFORM / MERGE / MOVE / CUT / INVENT

每个决策同时写 downstream repair。

---

# Phase 11：Scene Map

只有此时才正式进入场景级。

每场写：

- Source Origin
- Screen Function
- Goal
- Obstacle
- Turn
- Visible Externalization
- Consequence

---

# Phase 12：正文串行

```text
写当前单元
→ 更新 Handoff
→ 更新 Knowledge
→ 更新 Secret
→ 更新 Object / Resource
→ 更新 Setup / Payoff
→ 再写下一单元
```

不要几十集无状态自由生成。

---

# Phase 13：全局回归

每完成一个大阶段：

- 原作核心是否还在
- 改编新增是否形成新漏洞
- 人物是否漂移
- Reveal 是否公平
- 被删支线是否留下断裂
- 结局 Setup 是否充分

---

# Phase 14：Final

最终要求：

```text
原作核心可识别
+
影视版独立成立
+
目标媒介适配
+
长篇连续性可靠
+
正文可见可演
```
