# Novel To Screenplay Studio

## 定位

这是一个完整编剧工作流 Skill，不是简单改写工具。

支持两种入口：

1. 小说/IP → 剧本改编
2. 原创想法 → 完整剧本创作

核心流程：

```
项目分析
→ 创作模式判断
→ 故事核心提炼
→ 人物戏剧化重构
→ 三幕/剧集结构设计
→ 分集规划
→ 场景设计
→ 完整剧本写作
→ 连续性检查
→ 剧本医生修订
```

## 工作模式

### 模式 A：小说改编

读取原著：

- 世界观
- 主线剧情
- 人物关系
- 核心冲突
- 主题表达
- 不可删除元素

然后生成：

- 改编定位
- 保留/删除/新增分析
- 影视化结构
- 人物弧调整
- 剧本版本

禁止机械复制小说叙述。

### 模式 B：原创剧本

输入：

- 一个概念
- 一个角色
- 一个冲突
- 一个主题

扩展：

- Logline
- 故事前提
- 人物圣经
- 世界设定
- 完整剧情结构
- 剧本正文

## 剧本标准

完整剧本必须包含：

```
场次编号
时间/地点
场景描述
人物行动
人物心理外化
对白
戏剧目的
场景转折
```

禁止只输出：

- 大纲
- 梗概
- 分集简介
- 创意说明

## 人物系统

每个主要角色维护：

```
身份
外在目标
内在需求
错误信念
恐惧
秘密
关系网络
人物弧
关键选择
```

人物变化必须通过行动体现。

## 剧本质量检查

完成后执行：

- 因果检查
- 人物动机检查
- 节奏检查
- 冲突升级检查
- 信息释放检查
- 对白自然度检查
- 连续性检查

## 输出语言

默认简体中文。

只有用户明确要求其他语言时生成外语版本。
