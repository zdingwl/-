# v2.3.0 Release Notes

## Novel To Screenplay Studio 2.3

2.3 的重点是让类型真正参与 Story Engine，而不是只作为标签。

## Genre Engine

新增主入口：

`references/genre-engine.md`

当前包含：

- Romance
- Mystery
- Thriller / Horror
- Comedy
- Crime / Legal
- Family / Emotional Drama
- Fantasy / Sci-Fi
- Revenge / High-satisfaction
- Action / Adventure

## Primary / Secondary Genre

项目只锁定：

```text
Primary Genre
+
必要 Secondary Genre
+
Tone
```

不一次加载全部类型规则。

## Genre Contract

每个项目现在可以明确：

- Audience Promise
- Central Question
- Required Payoffs
- Acceptable Delays
- Forbidden Shortcuts
- Climax Expectation
- Ending Expectation

## Genre Payoff Ledger

用于追踪：

- 承诺
- Setup
- 阶段回报
- Major Payoff
- Final Payoff

避免作品不断承诺却不兑现。

## Genre Drift

Writer's Room 新增 Genre Review。

检查：

- 主类型体验是否仍然存在
- 次类型是否吞掉主类型
- 高潮是否仍属于该类型
- 慢燃是否被错误调成高频反转
- 悬疑是否靠突然证据
- 高爽是否依赖主角主动性

## 主要类型原则

### Romance

关系推进来自真实选择与代价，而非重复误会。

### Mystery

观众持续更新真相模型；最终答案必须有公平证据。

### Thriller / Horror

威胁、空间、资源和规则制造压力，不靠人物故意变笨。

### Comedy

笑点来自人物策略和处境升级，不是段子合集。

### Crime / Legal

区分事实真相与制度内可证明事实。

### Family Drama

允许慢燃，但关系、边界与权力不能长期静止。

### Fantasy / Sci-Fi

世界规则必须有成本、限制，并真实改变人物选择。

### Revenge / High-satisfaction

爽点来自主角主动布局、阶段兑现与对手适应。

### Action / Adventure

动作场景必须有具体目标、空间逻辑、策略变化与后果。
