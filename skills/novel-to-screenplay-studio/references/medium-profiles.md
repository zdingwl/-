# 媒介配置：电影 / 剧集 / 短剧 / 动画

同一个故事换媒介时，必须重新设计结构，而不是只改变长度。

---

# 2. 电影 / 长片

核心目标：

> 在有限时长内完成一个主要戏剧问题和一条集中人物弧。

优先：

- 单一清晰主线
- 少量强关系
- 早期建立目标
- 段落级升级
- 中段意义改变
- 高潮汇合
- 结尾完成情绪回收

警惕：

- 像剧集 Pilot，只负责建立世界
- 支线过多
- 中段重复
- 高潮由新信息临时救场

### 电影 Scene 观念

每场要有高功能密度。

常见组合：

```text
推进主线 + 改变关系
揭露信息 + 改变策略
完成 Setup + 制造新代价
```

---

# 3. 电视剧 / 流媒体剧集

需要同时管理：

```text
Season Engine
+
Episode Engine
+
Character / Relationship Engine
```

## Season Engine

回答：

- 为什么值得持续数集？
- 核心目标能否阶段推进？
- 对手是否会适应？
- 秘密能否分层？
- 关系会不会自然产生新局面？

## Episode Engine

每集至少有：

```text
当前问题
→ 当前目标
→ 行动
→ 阻力
→ 变化
→ 阶段回报
→ 下一问题
```

## A / B / C 线

只有有功能时才使用。

功能可能是：

- 节奏对照
- 主题镜像
- 主角关系压力
- 信息差
- 次级角色弧
- 后续 Setup

不能为了格式强行制造副线。

## Act-out

流媒体不一定有广告幕，但仍需要“意义转折点”。

---

# 4. 有限剧 / Limited Series

介于电影和长剧之间。

特点：

- 有明确终点
- 允许更深人物与支线
- 不需要无限可续
- 每集仍需独立变化

适合：

- 长篇小说
- 多视角悬疑
- 家族史
- 跨时间故事
- 复杂关系网

改编时尤其注意：

> 不要把小说章节直接当集数。

---

# 5. 短剧 / 微短剧

核心不是“更短”，而是：

> 单位时间内更高的有效变化密度。

有效变化：

- 目标
- 信息
- 风险
- 关系
- 权力
- 资源
- 身份
- 观众预期

## 单集微结构

```text
开场状态
→ 当前问题
→ 主角动作
→ 反制
→ 有效变化
→ 部分回报 / 新信息
→ 后果
→ 下一问题
```

## 禁止机械化

不要固定：

- 每 30 秒反转
- 每集必须打脸
- 每集必须巨大悬崖
- 每集一个随机新秘密

集尾应来自本集因果。

## 小说短剧化

优先：

- 压缩重复人物
- 压缩世界说明
- 提前人物处境
- 提高目标清晰度
- 重排秘密
- 让阶段回报更近
- 让每集有独立变化

---

# 6. 动画

动画允许：

- 非现实空间
- 极端动作
- 视觉变形
- 复杂世界
- 风格化表达

但编剧层仍必须满足：

- 目标
- 阻碍
- 因果
- 人物选择
- 场景变化
- 情绪回报

## 动画特有考虑

### 视觉动作语言

角色动作本身可以是人物塑造。

### 世界规则

奇幻能力 / 科技 / 魔法必须有一致规则和代价。

### 奇观预算

即使动画不受现实拍摄限制，也应考虑重复资产、场景复杂度和角色数量，尤其连续项目。

### 解释控制

世界越复杂，越要把规则放进人物行动，而不是大段百科说明。

---

# 7. 媒介转换检查

从一种媒介改另一种时检查：

```text
□ 主故事是否仍匹配新时长
□ Story Engine 是否匹配新集数
□ 信息释放速度已重排
□ 场景长度已重排
□ 角色数量适合新媒介
□ 每个单元的回报密度适配
□ 高潮位置已重新设计
□ 结尾不是原媒介的机械切割
```

核心：

> 换媒介 = 重构，不是拉长或切碎。
