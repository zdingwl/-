# Mystery Genre Profile

核心：

> 观众不断更新“到底发生了什么”的模型。

## 三层问题

```text
事实问题：发生了什么？
责任问题：谁做的 / 谁隐瞒？
意义问题：真相改变了什么？
```

## Mystery Engine

```text
问题
→ 调查 / 行动
→ 证据
→ 假设
→ 新矛盾
→ 模型更新
→ 更具体的问题
```

## 线索规则

好线索：

- 进入剧情行动
- 可被多种方式解释
- 回看时公平
- 改变人物策略

坏线索：

- 最后突然出现
- 只有作者知道
- 与前文无连接

## Red Herring

误导必须来自：

- 有限信息
- 人物偏见
- 合理假设
- 对手行为

不能靠作者欺骗观众。

## Reveal

强 Reveal 应改变：

- 嫌疑
- 目标
- 策略
- 关系
- 风险
- 对过去的解释

## 中段

中段最好不是“更多线索”，而是：

> 当前调查模型被证明根本不完整或方向错误。

## 高潮

必须依赖前文已有证据与人物推理 / 行动。

## Review

```text
□ 主要答案有公平证据
□ 信息差可追踪
□ 每次延迟都提供新价值
□ 角色不会凭作者知识推理
□ Reveal 后局势真正改变
```
