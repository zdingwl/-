# Action / Adventure Genre Profile

核心：

> 动作不是“发生打斗”，而是人物在高压条件下用身体行动解决目标，并承担即时后果。

## Action Engine

```text
明确目标
→ 空间 / 时间 / 对手限制
→ 行动计划
→ 计划受阻
→ 即时调整
→ 代价
→ 新位置 / 新目标
```

## 动作场景必须回答

- 人物想拿到 / 到达 / 保护什么
- 空间规则是什么
- 谁拥有优势
- 策略如何改变
- 场景结束后什么状态改变

## 避免

- 无目标打斗
- 越打越大但剧情不动
- 主角无限耐打
- 动作后世界恢复原样

## Adventure

强调：

- 旅程目标
- 新环境
- 资源管理
- 同伴关系
- 地图 / 线索
- 阶段性目的地

每个新地点都应改变玩法，而不只是换背景。

## 高潮

动作高潮最好同时解决人物最重要的选择。

## Review

```text
□ 动作有目标
□ 空间可理解
□ 策略发生变化
□ 伤势 / 资源有连续性
□ 动作改变后续剧情
```
