# Crime / Legal Genre Profile

核心：

> 事实、证据、制度规则与人物利益不断重新定义“什么能够被证明、什么值得被证明”。

## Crime Engine

```text
事件 / 犯罪
→ 调查
→ 证据
→ 利益阻力
→ 新事实
→ 策略变化
```

## Legal Engine

```text
事实
+
可采 / 可证明证据
+
程序
+
利益
+
道德选择
```

## 区分

“观众知道真相”不等于“角色能在制度内证明真相”。

这是律政戏的重要张力来源。

## 证据 Ledger

跟踪：

- 谁持有
- 谁知道
- 是否合法取得
- 是否可用
- 证明什么
- 有什么替代解释

## 对抗

强对手不只“邪恶”，还可能：

- 合法
- 程序正确
- 资源更多
- 拥有更可信叙事

## 高潮

最好同时解决：

- 事实
- 证明
- 人物价值选择

## Review

```text
□ 调查过程有因果
□ 证据来源可追踪
□ 人物不使用非法全知
□ 制度规则前后一致
□ 高潮不是突然证人 / 突然录像救场
```
