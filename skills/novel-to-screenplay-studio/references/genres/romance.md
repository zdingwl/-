# Romance Genre Profile

核心：

> 观众不是只等“在一起”，而是在观察两个人是否能够、是否应该以及以什么代价选择彼此。

## Story Engine

```text
吸引 / 需要
+
真实阻碍
+
选择
+
关系状态变化
```

## 必须追踪

- 为什么被吸引
- 为什么不能轻易在一起
- 双方分别想要什么
- 权力是否平衡
- 信任怎样建立 / 破坏
- 关系每个阶段发生了什么不可逆变化

## 有效阻碍

- 价值冲突
- 外部责任
- 利益冲突
- 身份 / 目标冲突
- 旧伤导致的策略
- 真正需要付出代价的秘密

## 弱阻碍

- 可以一句话解释清却拖十集的误会
- 人物突然不接电话
- 为分手而分手
- 随机第三者

## 关系节拍

```text
识别
→ 吸引 / 依赖
→ 边界测试
→ 信任行动
→ 更高风险暴露
→ 关系选择
→ 代价
→ 最终选择
```

不要求固定顺序。

## 高潮

爱情高潮最好是：

> 人物在外部代价下，用行动证明自己如何理解这段关系。

## Review

```text
□ 双方都有主动性
□ 靠近和疏远都有事件依据
□ 没有重复同一个误会
□ 亲密变化可见
□ 最终关系状态回应人物弧
```
