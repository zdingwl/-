# Fantasy / Sci-Fi Genre Profile

核心：

> 世界规则不是装饰，而是必须改变人物能做什么、不能做什么以及选择的代价。

## World Rule Contract

```yaml
world_rule:
  rule:
  visible_effect:
  cost:
  limitation:
  who_knows:
  exceptions:
  payoff:
```

## Story Engine

```text
规则
→ 人物利用规则
→ 获得优势
→ 付出代价
→ 发现规则边界 / 真相
→ 必须重新选择
```

## Worldbuilding

优先进入：

- 冲突
- 职业
- 法律
- 资源
- 关系
- 生存
- 技术 / 魔法使用后果

避免百科式说明。

## 能力系统

每个重要能力至少回答：

- 能做什么
- 不能做什么
- 代价是什么
- 为什么不能无限使用
- 谁能对抗

## Sci-Fi

科技概念必须产生：

- 社会后果
- 人物选择
- 新权力结构

而不只是酷设定。

## Fantasy

世界规则、阶层、血统、魔法、神话必须真实影响目标与代价。

## 高潮

最好使用前文建立的规则解决，而不是临时新增能力。

## Review

```text
□ 规则前后一致
□ 世界设定进入人物行动
□ 能力有代价与限制
□ 高潮没有突然新规则
□ 奇观服务因果和人物
```
