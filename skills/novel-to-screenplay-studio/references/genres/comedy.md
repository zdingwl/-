# Comedy Genre Profile

核心：

> 喜剧来自人物以自己独特、通常不完美的逻辑努力解决问题，并让局面升级。

## Comedy Engine

```text
目标
→ 错误 / 极端策略
→ 意外后果
→ 为掩盖后果采取更强策略
→ 更大局面
```

## 笑点来源

优先：

- 人物性格
- 身份落差
- 信息差
- 社会规则
- 关系权力
- 过度承诺
- 具体处境

避免：

- 与人物无关的段子拼接
- 每个人都像脱口秀演员
- 笑点让剧情暂停

## Callback

可以重复，但每次必须：

- 意义升级
- 关系变化
- 后果更大

## 情感

喜剧仍需要真实 Stakes。

没有人在乎结果，笑点很快失去重量。

## 高潮

人物最极端的旧策略通常会失败，迫使其采用新选择。

## Review

```text
□ 笑点来自人物 / 处境
□ 喜剧推动剧情
□ 重复笑点有升级
□ 情绪真相没有被笑点抹掉
□ 不用随机荒诞代替因果
```
