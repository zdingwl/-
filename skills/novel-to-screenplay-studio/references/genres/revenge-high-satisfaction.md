# Revenge / High-Satisfaction Genre Profile

核心：

> 观众先形成明确情绪债务，再通过主角主动行动获得阶段性掌控感与最终兑现。

## Engine

```text
情绪债务
→ 主角目标
→ 取回资源 / 信息 / 权力
→ 对手反制
→ 阶段兑现
→ 新代价
→ 更高层对抗
```

## 爽点不是随机打脸

有效回报：

- 谎言被拆穿
- 权力逆转
- 资源夺回
- 对手失去筹码
- 身份真相公开
- 主角完成主动布局

## 主角主动性

高爽模式最怕：

> 主角一直受害，关键时刻突然有人替她解决。

主要回报必须来自主角前面已经做出的选择、积累和布局。

## 对手升级

对手要：

- 学习
- 换策略
- 增加代价

不能每阶段都重复同一种羞辱。

## 高潮

最终兑现应同时解决：

- 外部复仇 / 目标
- 主角是否仍被旧伤定义
- 核心关系

## Review

```text
□ 爽点来自主角行动
□ 回报有阶段性
□ 对手会适应
□ 不重复同一种打脸
□ 兑现后产生新局面
```
