# Thriller / Horror Genre Profile

共同核心：

> 观众持续感受到威胁正在逼近，而人物必须在受限条件下行动。

## Thriller Engine

```text
威胁
→ 应对
→ 暂时控制
→ 新信息
→ 风险升级
→ 策略改变
```

## Horror Engine

除威胁外，强调：

- 未知
- 禁忌
- 脆弱性
- 失控
- 价值 / 身份污染
- 无法轻易回到旧状态

## 紧张来源

优先：

- 信息差
- 时间限制
- 空间限制
- 资源限制
- 道德选择
- 关系不可信
- 规则代价

避免：

- 人物为了剧情故意变笨
- 反复制造 Jump Scare
- 威胁无规则无限升级

## 规则

威胁越超自然，规则越要清晰。

观众不一定一开始知道规则，但作者必须知道。

## 高潮

不是简单“更大的怪物 / 更多追杀”，而是：

> 人物终于理解威胁并被迫做最高代价选择。

## Review

```text
□ 人物应对合理
□ 危险来自因果
□ 威胁会适应
□ 安全感不是无限重置
□ 高潮解决核心威胁或明确其意义
```
