# Script Doctor、修订顺序与质量门槛

目标：先找根问题，再改表面。

---

# 1. 诊断顺序

```text
Premise
→ 类型承诺
→ Story DNA
→ 主角主动性
→ 对抗与 Stakes
→ 因果链
→ 人物弧 / 核心关系
→ 全剧结构
→ 媒介适配
→ 分集 / 段落
→ 场景
→ 信息释放
→ 对白
→ 视觉化
→ 连续性
→ 格式
```

禁止结构坏了只做 Dialogue Polish。

---

# 2. 根问题格式

诊断必须写：

```yaml
issue:
  symptom:
  evidence:
  root_cause:
  impact:
  repair_level:
  recommended_change:
  downstream_effect:
```

---

# 3. Premise Gate

```text
□ 主角明确
□ 触发事件明确
□ 目标明确
□ 阻碍明确
□ 失败代价明确
□ 结局能回答核心问题
```

---

# 4. Adaptation Gate

仅改编项目：

```text
□ 原作核心情绪承诺仍在
□ 关键关系没有被误删
□ 改编取舍有功能理由
□ 内心戏完成影视化
□ 人物 / 支线压缩没有破坏因果
□ 时间与 Reveal 已重新设计
□ 新增场景解决实际屏幕问题
□ 影视版可独立理解
```

---

# 5. 主角主动性 Gate

```text
□ 主角反复做关键选择
□ 会改变策略
□ 自己的选择会制造代价
□ 主要胜利不是别人送来
□ 高潮依赖主角最终选择
```

---

# 6. 因果 Gate

重大节点：

```text
为什么现在发生？
谁造成？
主角当时知道什么？
为什么会这样选？
有没有更简单解决法？
如果有，为什么不能用？
结果制造了什么新压力？
```

---

# 7. 对抗 Gate

```text
□ 对手有自身目标
□ 拥有可信资源
□ 会适应主角行动
□ 升级不是重复同一招
□ 后期代价高于前期
```

---

# 8. 人物 Gate

```text
□ 行为符合目标、知识和压力
□ 角色有矛盾而非单一标签
□ Arc 由选择证明
□ 核心关系通过事件变化
□ Voice 有差异
```

---

# 9. 结构 Gate

```text
□ 开头建立异常和目标
□ 第一重大选择改变局面
□ 中段改变玩法 / 意义
□ 低谷来自因果
□ 高潮汇合主要压力
□ 结局回应外部目标、关系和人物弧
```

---

# 10. 媒介 Gate

## 电影
- 是否收束成一个完整主问题？

## 剧集
- Season Engine 是否能持续？
- 每集是否有自身变化？

## 短剧
- 单位时间是否有有效变化？
- 是否避免机械反转？

## 动画
- 世界规则是否清楚？
- 奇观是否仍服务人物和因果？

---

# 11. Scene Gate

每场：

```text
□ 有目标
□ 有阻碍
□ 有策略
□ 有反制
□ 有转折
□ 有 Value Shift
□ 有后果
□ 删除会造成损失
```

---

# 12. Dialogue Gate

```text
□ 台词在做事
□ 不重复画面
□ 不复述双方已知背景
□ 有潜台词
□ 有角色差异
□ 允许沉默和回避
□ 不是主题演讲
□ 中文自然可演
```

---

# 13. Information Gate

```text
□ Reveal 改变局面
□ 观众困惑是有意而非信息缺失
□ 悬念有推进而非只拖答案
□ 人物不会使用未知信息
□ 误导有公平证据
```

---

# 14. Continuity Gate

```text
□ 时间
□ 地点
□ 人物知识
□ 伤势
□ 关系
□ 物件
□ 资源
□ 秘密
□ 世界规则
□ Setup / Payoff
```

---

# 15. Anti-AI Gate

检查：

- 模板连接词
- 所有人说话同一种节奏
- 大量情绪标签
- 解释型台词
- 万能悬念句
- 每场结构机械相同
- 每个转折都像“突然”
- 人物过度理性、过度完整

---

# 16. Revision Passes

推荐：

```text
Pass 1  Premise / 类型承诺
Pass 2  因果 / 主角主动性
Pass 3  改编完整性（如适用）
Pass 4  人物 / 关系
Pass 5  全剧结构
Pass 6  分集 / 段落
Pass 7  场景
Pass 8  信息 / Reveal
Pass 9  Dialogue
Pass 10 Visual
Pass 11 Continuity
Pass 12 Compression
Pass 13 Anti-AI
Pass 14 Final Proof
```

---

# 17. 修订优先级

分三档：

## P0
不改就让故事不成立：
- 因果断裂
- 人物知识错误
- 结局无准备
- 主角无目标
- 改编删掉核心

## P1
严重损伤观看体验：
- 中段重复
- 场景静止
- 关系无变化
- 信息释放失衡
- 类型承诺断裂

## P2
精修：
- 台词
- 节奏
- 用词
- 格式
- 轻微压缩

---

# 18. 最终剧本完成标准

```text
□ 故事可以用一句话说清
□ 主角有明确行动线
□ 核心冲突由因果推进
□ 人物弧在高潮得到证明
□ 结构适配目标媒介
□ 每场有变化
□ 对白是行动
□ 重要心理已视觉化
□ 信息释放可追踪
□ 连续性无硬冲突
□ 格式统一
□ 没有分镜/生成模型指令混入
```
