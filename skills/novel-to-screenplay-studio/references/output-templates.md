# 17. 用户只要完整剧本时

不要输出模板大全。

直接：

```text
必要的 2–5 条前置说明（如确有必要）
→ 完整剧本正文
```

如果必须做重大合理假设：

```text
暂定：目标媒介 / 时长 / 集数
```

一句说明即可，然后继续完成任务。
