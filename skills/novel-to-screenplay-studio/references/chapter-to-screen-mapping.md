# 章节 / 卷 → 影视结构映射

本文件回答：如何从小说章节得到电影段落、剧集或短剧单元。

核心：

> 不映射编号，映射功能和状态变化。

---

# 1. 先给章节打功能标签

每章可有多个：

- PLOT：推进主因果
- CHARACTER：证明人物
- RELATIONSHIP：改变关系
- REVEAL：改变信息
- WORLD：建立规则
- SETUP
- PAYOFF
- TRANSITION
- ATMOSPHERE

---

# 2. 删除纯重复

若连续多章承担同一功能且没有新后果：

- 合并
- 压缩
- 选择最强版本保留

---

# 3. 找“状态边界”

影视结构优先在这些点切换：

- 目标改变
- 权力改变
- 关系改变
- 身份改变
- 风险改变
- 认知改变
- 资源改变
- 选择变得不可逆

这些比“章节结束”更重要。

---

# 4. 形成 Sequence

相邻素材如果共同回答同一个阶段问题，就归为同一 Sequence。

```yaml
sequence:
  current_question:
  goal:
  source_chapters:
  escalation:
  turn:
  exiting_state:
```

---

# 5. Sequence → Episode

一集不应只是“塞满规定时长”。

优先选择能形成：

```text
问题
→ 行动
→ 阻力
→ 变化
→ 阶段回报
→ 新问题
```

的 Sequence 组合。

---

# 6. 一个章节可能产生多个场景

当一章包含：

- 多地点
- 多目标
- 多次 Value Shift
- 不同时间段

应拆。

# 7. 多个章节可能只产生一场

当多章只是：

- 重复心理
- 重复等待
- 同一背景说明
- 同一谈话被分章

应合并。

---

# 8. 映射质量检查

```text
□ 没有一章一集机械对应
□ 集边界来自戏剧变化
□ 删除章节后因果已修复
□ 合并人物后知识状态已修复
□ Reveal 位置按影视效果重排
□ 每个影视单元都有退出状态
```
