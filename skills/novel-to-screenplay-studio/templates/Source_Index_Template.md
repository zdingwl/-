# Source Index Template

用于长篇小说、多文件素材在正式改编前建立全局索引。

```yaml
source_index:
  project:
  source_scale:
  total_files:
  total_volumes:
  total_chapters:
  ingestion_status:

  units:
    - source_id:
      file:
      volume:
      chapter:
      range:
      pov:
      story_time:
      locations:
      characters_present:
      major_event:
      character_choice:
      consequence:
      relationship_change:
      information_added:
      secret_change:
      setup:
      payoff:
      emotional_value:
      adaptation_priority: high | medium | low
      notes:

  global_characters:
  global_timeline:
  global_secrets:
  global_setups:
  global_payoffs:
  unresolved_source_questions:
```

## 原则

索引记录“事实、功能和变化”，不是重新写一遍章节摘要。
