# Relationship Map Template

```yaml
relationship:
  character_a:
  character_b:

  surface_relation:
  private_relation:
  shared_history:

  a_wants_from_b:
  b_wants_from_a:
  mutual_need:
  mutual_threat:
  attraction_or_dependency:
  hidden_truth:

  power_balance:
    start:
    midpoint:
    end:

  trust_state:
  unresolved_conflict:
  turning_points:
    - unit:
      event:
      before:
      after:

  rupture_point:
  repair_condition:
  final_state:
```

## 核心规则

不要只写“关系升温 / 恶化”，必须记录是什么事件改变了权力、信任或依赖。
