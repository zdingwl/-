# Secret Ledger Template

```yaml
secret:
  - id:
    content:
    origin:
    owner_or_holder:
    audience_knows: true | false
    protagonist_knows: true | false
    characters_who_know:
    characters_who_suspect:
    characters_who_falsely_believe:
    public_status:
    first_hint:
    planned_reveal:
    reveal_trigger:
    reveal_consequence:
    affected_goal:
    affected_relationship:
    affected_strategy:
    status: hidden | partial | revealed | disproven
```

## 规则

秘密的价值来自“揭露后改变什么”，不是来自长期不说。
