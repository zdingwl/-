# Project Templates

这些模板用于把长期编剧项目从“聊天上下文”变成显式项目状态。

## 基础项目

- `Project_State_Template.md`
- `Story_Bible_Template.md`

## 小说 / IP 改编

- `Source_Index_Template.md`
- `Source_Analysis_Template.md`
- `Chapter_Function_Map_Template.md`
- `Adaptation_Bible_Template.md`
- `Adaptation_Risk_Report_Template.md`

## 人物与连续性

- `Character_Bible_Template.md`
- `Relationship_Map_Template.md`
- `Timeline_Template.md`
- `Knowledge_State_Template.md`
- `Secret_Ledger_Template.md`
- `Foreshadow_Template.md`

## 写作生产

- `Episode_Map_Template.md`
- `Scene_List_Template.md`
- `Script_Draft_Template.md`
- `Revision_Report_Template.md`

## 最小初始化

原创项目至少创建：

```text
Project State
Story Bible
Character Bible
```

长篇改编至少创建：

```text
Project State
Source Index
Story Bible
Adaptation Bible
Timeline
Secret Ledger
Setup / Payoff
Knowledge State
```

模板是状态容器，不要求把所有字段展示给用户。
