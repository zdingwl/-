# Review Conflict Template

```yaml
review_conflict:
  id:
  issue:
  reviewer_a:
  reviewer_b:
  shared_evidence:
  disagreement:
  protected_elements:

  options:
    - option:
      gains:
      losses:
      downstream_changes:
      re_review_needed:

  lead_decision:
  decision_reason:
  affected_units:
  decision_log_update:
  status: unresolved | decided | implemented | verified
```

## 原则

冲突意见不能用“各改一半”自动解决；主编剧必须明确裁决。
