# Episode Map Template

适用于剧集与短剧。

```yaml
episode:
  number:
  title:
  opening_state:
  current_question:
  episode_function:
  protagonist_goal:
  main_obstacle:
  protagonist_action:
  opposition_response:
  key_information:
  relationship_change:
  power_change:
  risk_change:
  emotional_or_genre_payoff:
  reveal_or_reversal:
  setup_planted:
  payoff_completed:
  ending_consequence:
  ending_question:
  next_episode_value:
  ending_state:
```

## 检查

一集删掉后若全剧几乎不受影响，说明该集功能不足。
