# Executive Review Template

Lead Writer / 主编剧最终裁决。

```yaml
executive_review:
  project:
  draft_version:
  reviewed_scope:

  protected_elements:
  review_summary:
    structure:
    character:
    adaptation:
    medium:
    continuity:
    dialogue:

  conflicts:
    - conflict_id:
      reviewers:
      disagreement:
      lead_decision:
      reason:
      gains:
      losses:
      affected_units:

  final_priorities:
    must_fix_p0:
    should_fix_p1:
    polish_p2:

  do_not_change:
  rewrite_order:
  re_review_plan:
  target_next_version:
  unresolved_risks:
  approval_status: blocked | rewrite_required | conditional_pass | pass
```

## 原则

Executive Review 不是把所有 Reviewer 建议全采纳，而是统一为一份可执行的重写方案。
