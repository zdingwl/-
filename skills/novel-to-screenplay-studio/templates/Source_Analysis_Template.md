# Source Analysis Template

用于小说 / IP / 真实素材改编前的源素材拆解。

```yaml
source_analysis:
  source_title:
  source_type:
  total_scale:
  structure_summary:

  core_story:
  emotional_core:
  protagonist_line:
  core_relationship:
  main_conflict:
  theme_question:
  ending_truth:

  timeline:
  major_events:
  major_reveals:
  major_setups:
  major_payoffs:

  characters:
    - name:
      function:
      uniqueness:
      merge_candidate: true | false

  subplots:
    - name:
      function:
      connection_to_main:
      keep_value:

  irreplaceable_elements:
  transformable_elements:
  removable_elements:
  screenability_problems:
  adaptation_risks:
```

## 不要做什么

- 不把“章节总结”当“源素材分析”。
- 不在尚未理解全局时直接决定分集。
- 不因为原作存在就默认全部保留。
