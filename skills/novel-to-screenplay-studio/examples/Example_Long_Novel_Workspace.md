# Example：百万字网文改编项目工作空间

假设：

- 120 万字
- 8 卷
- 420 章
- 目标：24 集剧集

初始化：

```text
Project_State.md
Source_Index.md
Story_Bible.md
Adaptation_Bible.md
Character_Bible/
Relationship_Map.md
Timeline.md
Secret_Ledger.md
Knowledge_State.md
Setup_Payoff.md
Chapter_Function_Map.md
Adaptation_Risk_Report.md
Episode_Map.md
Scene_List/
Drafts/
Revision/
```

## 第一阶段

不写剧本。

先扫描 8 卷 / 420 章，建立 Source Index。

## 第二阶段

按卷读取，每章只提取：

- POV
- 事件
- 选择
- 后果
- 关系
- 信息
- 秘密
- Setup / Payoff

## 第三阶段

读完结局后才锁：

- Story DNA
- Ending State
- Adaptation Fidelity
- 24 集总体阶段

## 第四阶段

建立 Chapter Function Map。

420 章不对应 24 集。

先压成若干 Sequence，再组合成 24 个 Episode。

## 第五阶段

完成 Episode Map 后才正式 Scene List → Draft。

这样可以避免：

- 前 50 章决定全剧
- 章 = 集
- 人物后期设定丢失
- 伏笔忘记
- 改到一半发现结局不兼容
