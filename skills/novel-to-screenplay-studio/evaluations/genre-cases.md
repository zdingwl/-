# Genre Engine 回归案例

## Case 1：慢燃爱情

要求：

- 不靠重复误会
- 关系每集有真实变化
- 不强制高频反转

检查：

- Romance 模块是否正确
- 是否被 High-satisfaction 规则污染

## Case 2：公平悬疑

要求：

- 最终真相回看有公平证据
- Red Herring 合理
- Reveal 改变策略

检查：

- 是否突然出现关键证据
- 人物是否全知

## Case 3：惊悚

要求：

- 人物不能故意变笨
- 威胁有规则
- 空间限制明确

## Case 4：喜剧

要求：

- 笑点来自人物和处境
- 不是段子合集

## Case 5：律政

要求：

- “事实真相”和“可证明事实”有区分
- 证据来源可追踪

## Case 6：家庭慢燃

要求：

- 事件不需要高密度
- 关系与边界持续移动

## Case 7：奇幻

要求：

- 魔法能力有成本与限制
- 高潮不得突然新增能力

## Case 8：复仇爽剧

要求：

- 主角主动布局
- 对手适应
- 不重复同一种打脸

## Case 9：动作

要求：

- 每个动作场有具体目标
- 动作改变剧情状态

## Case 10：混合类型

输入：

`Mystery + Family Drama`

检查：

- Mystery 仍是 Primary
- Family Drama 增强人物与情绪
- 不同时加载所有类型硬规则
