# 回归测试案例

---

# Case 1：长篇小说 → 电影

```text
素材：一部长篇家庭悬疑小说，双时间线，12 个主要人物。
目标：改成约 2 小时电影。
要求：保留“母女关系”和最终真相，允许合并人物与支线。
```

观察：

- 是否敢删
- 是否保住核心关系
- 是否重排 Reveal
- 是否把双时间线变成有效影视结构

---

# Case 2：网文 → 8 集 Limited Series

```text
素材：约 40 万字都市悬疑网文。
目标：8 集流媒体剧。
要求：不按章节切集；保留主角职业设定与结局。
```

观察：

- Season Engine
- Episode Engine
- 支线筛选
- Knowledge State
- 中段是否重复

---

# Case 3：网文 → 60 集短剧

```text
素材：重生复仇网文。
目标：60 集短剧。
要求：高爽但不能重复打脸，不机械每集反转。
```

观察：

- 有效变化密度
- 阶段兑现
- 对手适应
- 是否把章节点机械当集尾

---

# Case 4：文学小说 → 人物电影

```text
素材：大量第一人称内心独白，外部事件少。
目标：现实主义电影。
要求：克制，不强行商业爽点。
```

观察：

- 内心戏外化
- 道具 / 空间 / 选择
- 是否允许慢燃
- 是否过度解释

---

# Case 5：多 POV 小说 → 动画剧集

```text
素材：复杂奇幻世界，5 个 POV。
目标：12 集动画。
要求：世界规则保持一致，减少说明性台词。
```

观察：

- POV Map
- 世界规则
- 信息分配
- 视觉动作
- Story Bible

---

# Case 6：原创电影

```text
概念：一个失忆律师发现自己曾为真正的凶手赢下无罪判决。
目标：悬疑电影。
```

观察：

- Concept → Premise
- 主角主动性
- Reveal 公平
- 高潮是否回应道德主题

---

# Case 7：原创剧集

```text
概念：一家危机公关公司专门替权贵处理丑闻，主角发现自己家人的旧案与客户有关。
目标：10 集剧集。
```

观察：

- Season Engine
- Episode Engine
- 客户单元与主线如何结合
- 对手适应
- 关系持续性

---

# Case 8：原创爱情慢燃

```text
目标：8 集现实主义爱情剧。
要求：不靠重复误会，不需要高频反转。
```

观察：

- 关系变化
- 潜台词
- 细微 Value Shift
- Skill 是否错误套用短剧规则

---

# Case 9：连续性压力

```text
目标：40 集家族商业悬疑。
元素：股权、遗嘱、双重身份、伤势、关键 U 盘、多层秘密。
```

观察：

- Knowledge State
- Object Ledger
- Resource State
- Setup / Payoff
- Timeline

---

# Case 10：Script Doctor

输入一版：

- 主角被动
- 中段重复
- 对白很好看
- 结局突然出现新证据

要求：

> 不改台词，先找根问题。

观察：

- 是否从结构修
- 是否识别主角主动性
- 是否修 Setup
- 是否按优先级给方案
